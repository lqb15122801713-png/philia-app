## 基准裁定备注（试样 vs 文字冲突已按规则取舍）

- 页边距：试样 22px → 冻结决策 #23 全域 16px（任务书文字优先）。
- 字阶：试样 9.5/10.5/12.5/13.5/15 等 → 就近冻结档 11/12/14/17/20（字阶冻结=文字冻结项）。
- 完成态透明度：任务书 43% vs 试样 .45 → 取试样工艺值 .45（版式工艺以试样为基准）。
- 步名：试样「造型」→ 服务端 StepLabel「精修」（数据口径以文字/服务端为准，三端一致）。
- 来源签「客户指定」：assignSource 仅 auto/merchant/null，客户指定单同写 auto（S4 create 口径）
  → 轴块按 S4 appt-utils 统一口径显示「自动派单/商家改派」（疑点 U2-4 报产品侧）。
- frontdesk 顶栏副行（试样「全店 N 单 · M 美容师在班」）：全店计数在员工端无数据通道
  （疑点 U2-1 同根），取规格书骨架口径「门店 · 周X · 你的排班段」真实数据。

## 动效纲领抽验记录

- 按下反馈：dock/轴块/主钮/segment/stepper 全部 scale 0.92（或 0.98 大面）+ duration-120 + ease-philia-spring ✓
- 时长：toast 3200ms 自消（沿既有）、展开/收起 ≤300ms、无 >500ms 动画 ✓
- 只动 transform/opacity（浮层、按下）✓；加载 >300ms 骨架禁转圈 ✓
- 空态三件套：插画位=lucide 墨色线图标（emoji 禁令）+ 规格书原文 + 重试/行动真链路 ✓
- prefers-reduced-motion：u1 体系未注册全局降级媒体查询——标记为全端待办（与客户侧 U1 同现状，不属本批新增缺口）
