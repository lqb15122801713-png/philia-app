## 三、消缺与取舍报备（明面）

1. **寄养疫苗硬校验=纯客户端**（server create 无闸）——本片仅留证（疫苗证明上传列），补服务端闸=行为变更单列报备（若产品要「证明+有效期双要件」须另批）；
2. **栅格只收窄不扩**：循环上限仍固定 7 天——暖阳 14 天档中 >7 天部分「能约不能看」，已注释明面（暖阳看满 14 天=另批栅格扩窗）；
3. **协议文本双源同帧**：server 快照常量（config/agreements.ts）=客户端 copy 全文（copy/agreement.ts）逐字一致，改版须双侧同步换版号（改版不回溯历史留痕）；
4. **预付状态机裁**：仅 pending→registered 可确认；checkin 只翻 registered（pending 未确认不核销，留店家先 confirm）——「未确认也核抵」=另批；
5. **53.3 既有夹具适配**（未动断言）：栅格收窄后 PR-3 钉阿强进行中单无槽可落 409→改钉丽丽+顺延探测（CONFLICT 顺延回滚零副作用）；
6. **断点续跑伤**：O 限额断点致 appointment.ts 一处注释 opener 被吞+两 insert 缺 createdAt——P 按 HEAD 恢复+补齐（并列在案）；
7. **环境坑**：curl 中文 JSON 体经 bash 编码绞坏两见（夹具名乱码）→改 node 直写 JSON 修字在案；
8. **已建核销 2 件**=盘点表标注口径，零施工零断言新增。
