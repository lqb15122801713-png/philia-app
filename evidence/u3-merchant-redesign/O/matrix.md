## 基准裁定备注

- 字阶：试样 9.5/10.5/12.5/13.5 等 → 冻结档 11/12/14（字阶=文字冻结项优先）；26/32 展示档用于数据卡。
- 状态胶囊五态锁定：live 薄荷底墨字 / wait 墨 6% / done 细线描边 / amber 柠檬底墨字 / red #D92D20 底纸面字
  （red 为唯一浅字组件，规格书 §0 例外口径；墨轨奶油字同理在轨内）。
- 墨轨项文案 12px（试样 12.5 归档）；分组小标题 11px 宽距 35% 透明 ✓。
- 订单「已完成」chip 不渲染（接口仅 paid/shipped/refunding 三队列，不造归档假数据）。
- 预约列表行内确认/婉拒退役（S4 后确认链路归详情页；列表纯读按规格书 §3）。
- 财务红线遵守：无趋势图/环比同比（TrendChart/PaymentSplit/StaffTable 退役）；流水=listForStore(paidAt)+pendingPayments 聚合（现成接口）。
- 「联系员工」=就地展开 staffList 真值信息卡（staff 表无电话字段，不编造）。
- 「＋新增预约/入住登记」=真实口径提示（商家端无新建/无 checkin 权限），不做假表单。

## 动效纲领抽验

- 按下反馈：墨轨项/柠檬钮/细线钮/chips/行卡全部 active:scale 0.92–0.98 + duration-120 + ease-philia-spring ✓
- 只动 transform/opacity；行 hover 用 160ms standard 背景色（颜色过渡非布局）✓
- 加载 >300ms 骨架（脉冲条/卡轮廓），全域无转圈（存量 Loader2 随页面重写清零）✓
- 无 >500ms 动画；弹层（发货/编辑/打标）沿用既有 Modal 250ms 内 ✓
