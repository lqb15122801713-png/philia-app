# 功能尺寸表（UX 裁衣规则）

> 由来：老板 2026-09-21 定调——"UX 只是负责做衣服，但衣服必须让我们的功能穿得上。"
> 本表=三端功能的"身体尺码"。**UX 每屏设计必须挂住本表对应功能点；画出不存在的功能=废稿；改变交互步数=废稿。**
> 维护：项目经理窗口（功能变更随批次更新）。发给谁：UX 设计总监（裁衣依据）/ 产品（忠实度验收对照）/ QA（功能流不被衣服破坏的测试依据）。

## 一、铁律（裁衣四不许）

1. **不许画不存在的功能**：稿中每个元素必须能回挂本表功能点；新功能想法→写成建议交产品经理评审，不许直接画进稿。
2. **不许改交互步数与路径**：体验条款是物理约束——预约 2 屏不能画成 3 屏，收银三步不能画成四步，拍照≤2 击不能变成三步。
3. **不许丢功能入口**：信息层级可重排，但每个功能入口必须有落点（含三级账号差异：clerk 看不见的钱、manager 的审批、owner 的设置，稿中必须体现"不同角色看到不同世界"）。
4. **不许为美观牺牲计时项**：计时七条款（注册≤30秒/预约≤3步/加载<2秒/收银≤30秒/零弹窗/拍照≤2击/六步≤3分钟）——视觉变更不得增加任何一步操作耗时（大图/动效须评估加载代价）。

## 五、通用尺码

- 空态三句话结构（是什么/为什么/去哪）；异常态必有"能回哪去"出口件（W1）；
- 品牌色板按 CJ-0921-10 老板三色裁定：**深棕（主墨/深色密度位）/卡其（次阶）/淡黄（主背景/点睛）**；亮柠檬黄（FDC830）与深绿退场——原 VI v1.1 冻结色板进入 v2 修订流程，token 映射表同步更新；
- "守护值"概念废止（v9.2 口径，不建第四本账）——稿中不得再出现；
- 占位内容零容忍：档名/价格未解冻前一律置灰占位+注明，不得硬编码。
