## 件 1 · 微光=永久普通会员（免费档豁免有效期+懒冻结）

**修法**：
1. `currentMembership`（services/rebate.ts）懒冻结闸门前加档判：`plan_key='plan_weiguang'`（实际读默认档键，见件 2）→ **永不冻结**（免费档无到期语义）；
2. openFree 落库仍写 expires_at（结构不动），**读侧与展示侧对免费档忽略有效期**：A-3 微光卡不显示有效期/到期日；到期提醒条（30/7 天）对微光不渲染；规则明面 r3 对微光态换文案键「免费档永久有效」；
3. QA40-D11 闭环口径=「免费档永久普通会员，无到期无冻结」——客户端给客户一句明白话（文案键）；
4. 补验用例（QA）：微光号 expires_at 过后 → 不冻结、回馈金账户不冻结、页面无到期字样。

## 件 2 · 「注册默认档」端口化（plan_weiguang 硬编码改配置一行）

**修法**：
1. member_plans 增全局键 `default_plan_key`（值='plan_weiguang'，配置端口会员档页签可改——版本化留痕同族）；
2. openFree 硬编码 `'plan_weiguang'`（membership.ts:341 行族）改读键；sell 端点档校验同步；
3. 0016 幂等种子（PD-02 B2/Y6）随批带该键种子行；
4. 纪律注记（CJ-0925-10②）：经营参数类争议不再呈老板——此类「默认档」级参数以后直接端口化，不留硬编码。

## 件 3 · 寄养负责人指派机制（CJ-0925-11：寄养单必指派+差评 −8 扣负责人）

**修法（字段/动作）**：
1. **字段**：零新字段——复用 `appointments.staff_id`（寄养单现可空=漏洞根因，37 号档 A5 门径①）；语义=寄养负责人；
2. **动作**：寄养单创建（appointment.create 寄养型）→ **必须指派负责人**（员工端寄养受理动作含负责人选择；默认=当班寄养岗，可改）；核销/退房人默认=负责人，可改派（店长权限+留痕）；
3. **差评 −8 归属**：寄养单差评 → 扣 `staff_id`（负责人）——CJ-0925-11 落地，37 号档 A5 门径①封死；未指派=不允许（创建即拦）；
4. 历史单不补账（P-2 已拍）；洗护/美容单既有派单逻辑不动；
5. 补验用例（QA）：寄养单未指派=创建拒（明文）；寄养单差评→负责人 XP −8 落账；改派留痕可查。
