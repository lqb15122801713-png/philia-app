## 使用规则

1. **同刻活跃上限 3 个窗口**（老板验收传话的承受力）；干完活的窗口封存，角色卡在记忆指令里不会丢。
2. 窗口之间不互相传话——一切经老板或项目经理窗口中转，事实以档案文件为准。
3. 老板在任何窗口说完裁定，把那句话贴进项目经理窗口 + 一句"记台账"，即完成留痕。
4. 口诀：**新窗口读档案，新裁定找项目经理。**
