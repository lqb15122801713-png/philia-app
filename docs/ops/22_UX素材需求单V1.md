# 素材需求单 V1（UX 设计总监 → image_generation 自产，项目经理验收把关）

> 依据：CJ-0922-02 组合分工（手排结构不变+素材通道新增）。
> 原则：真素材嵌 HTML——"AI 感堆叠"的解药是真照片真插画；施工时全部换真实门店照片+真实数据。
> 验收口径（逐件过）：毛发质感不穿帮 / 人手不畸变 / 无乱码文字 / 暖色调与三色纪律同温（sepia 暖黄，不偏冷不偏品红）/ 无"AI 网红脸宠物"（过度大眼、过度磨皮、卡通化=废件）。

**不生成清单（纪律）**：不生成带文字/标语的图（AI 文字必乱码）；不生成人手为主的特写（畸变高危，洗护师画面等施工时门店实拍）；不生成"可爱插画"（方向红线，蓝图线稿已手绘承担）。

**后处理口径**：AI 生成水印（左下「AI生成」）一律裁除（crop 至水印线以上）；统一过 sepia 暖调校验；废件当场标注不留档。

**施工替换纪律**：本批素材为原型期占位——施工时按《门店拍摄清单》全部替换为真实门店照片+真实数据（拍摄清单随《设计规范 v2.0》交付）。
