## 〇、执行口径（动手前先读）

1. **分工（CJ-0921-07 不变）**：真机操作 = 产品侧 / 门店；QA 出用例、收证据、下判定。无证据不判定。
2. **证据链**：每条用例须留——机型 / 系统 / 浏览器 / 网络态、录屏或连续截图、计时读数（掐表法照 13 号档 §八）。
3. **计时纪律**：每条计时用例测 3 次，最大值与中位数双记，最大值超线即 ❌；计时统一口径 = 4G 节流 LCP。**读数未到=待实测（9-24 门店读数确认不存在〔CJ-0926-01②〕，挂换皮后统一走测）。**
4. **弹窗口径（已定）**：原生 alert/confirm/prompt 及营销、授权类打断弹窗为 0；设计内确认流不计。
5. **双层标记分离**：本包只判「功能实现已确认」；「数据结构已确认」归监理（B 窗）。
6. **QA 边界**：只上报不指挥施工；改进方向为建议性质，方案归产品经理。
7. **判定词**：✅通过=证据充分（注明来源）；⚠️部分通过=主链路已证、子项待证（列明）；❌不通过=证据证伪或冻结规范违反；待实测=无有效证据；**🧊豁免挂项=老板书面豁免（9-29），判定状态如实保留，补证过才销项**。
8. **证据形态分级（V1.3 明文化）**：①真机/生产实证=主证据；②产品侧复核意见书（逐件实证+截图目检）+生产 smoke=有效证据链（验收链独立环节，非施工方自报）；③施工方卷宗/e2e=辅证。**页面呈现与计时类的真机终验统一挂「换皮后统一走测」——凡据此判 ✅ 者一律注明「真机终验挂统一走测」。**
9. **勾权纪律**：证据到+判定过才勾 QA-01；执行方自报不作数；**豁免勾=老板书面豁免裁定（V1.4），豁免行 🧊 挂账，补证不过=翻案回炉**。
