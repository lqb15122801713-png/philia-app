# Philia 首页运营位内容选题与转化文案 V1.0

> 编制：运营总监（Kimi）｜2026-09-21｜**这份发 UX 设计总监+产品经理**
> 分工：UX 负责怎么摆（版式/组件/动效），运营负责摆什么（选题/人群/文案/轮换规则）。
> 基调（老板定）：高端品牌感、安静但有存在感、**零弹窗**——营销内容只出现在卡片/横幅/列表位，永不打断用户。

## 一、文案纪律（验收一票否决）

1. **三行制**：主文案≤12字（记忆点）＋副文案≤20字（说清规则）＋行动词2~4字。超出即砍；
2. **语气**：像朋友说话，不吆喝。禁电商腔（"立省/疯抢/限时秒杀/最后一天"）、禁感叹号连用；
3. **红线词**：只说"回馈金"，**禁说"返现/返钱"**；禁提"自动续费"；禁"充值"字眼（年费≠储值）；禁藏规则（回馈金规则会员页明面展示，共创会铁律）；
4. **一页最多一个营销卡**：首页同时只许一个主题在运营位，轮换不堆砌；
5. 数字必须真：比例（2%/5%/10%）、日期（11日/22日/次月5日）、价格（199/299/599）——与共创会落槌一字不差。

## 三、轮换逻辑（给UX/产品的展示规则）

1. **优先级**：S5到账（仅3天）＞S3/S4会员日（仅当日）＞S6生日周＞S9唤醒＞S1开卡（未注册）＞S2升级（微光）＞S7首单＞S8常态；
2. **人群分屏**：同一位置按登录态/档位显示不同选题——非会员见S1，微光见S2，付费会员见S5/S3/S6，**付费会员永不看到开卡引导**（高端品牌感的第一条：不对已付费的人喊"快来买"）；
3. **安静兜底**：任何时段没有命中的选题，显示S10品牌空位——品牌语+服务三分类，不硬塞内容；
4. **会员日双倍回馈金**为新增权益项，需老板拍板后上线（归体验批G2）；未拍前S3/S4暂缓，仅备稿。

## 四、替换既有作废内容

v9.1首页banner"秋日焕新洗护季·会员全年9.5折"——**"9.5折"为作废口径**（会员终版=回馈金2/5/10%，非折扣），按本清单S10品牌空位或S2替换；价格展示一律"全员同价+会员消费再返"口径。

## 五、验收口径（UX成稿后我复核）

1. 三行制逐条过；红线词grep=0；2. 非会员/微光/付费三态截图各一，开卡引导不得出现在付费会员首屏；3. 会员日替换逻辑在11日/22日实机验证；4. 全部数字与共创会落槌一致；5. 零弹窗——任何形式的强制弹层直接打回。
