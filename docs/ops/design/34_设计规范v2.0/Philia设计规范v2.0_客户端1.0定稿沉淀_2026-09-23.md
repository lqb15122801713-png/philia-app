## 一、VI 色纪律 token 全表（冻结）

色纪律 = V3 冻结口径（CJ-0921-12③④）：**深棕主体 / 纸白底 / 淡黄点睛（每屏 ≤2 处）/ 卡其次阶**。全部中性色向品牌色温染色——纯 `#FFFFFF` 页面底、纯 `#000000` 文字一律禁用（白卡 `#FFFFFF` 仅作卡片面，是唯一的白）。

## 二、字体系统（三轨制）

| 轨 | 字体 | 字重 | 用途 | 气质 |
|---|---|---|---|---|
| 衬线轨 | Noto Serif SC（退路 Songti SC / SimSun） | 900 为主 | 宣言、屏级大题、卡面档名、证书题、日报题 | **编辑感**——杂志封面，不是工具 |
| 无衬线轨 | 系统栈（-apple-system / PingFang SC / Microsoft YaHei） | 400/600/700/800 | 正文、列表、按钮、UI 默认 | 干净执行 |
| 等宽轨 | JetBrains Mono（退路 SF Mono） | 400/500/700 | 编号、金额、时间、溯源行、eyebrow 标签、规则明面 | **档案感**——安心研究所语言 |

### 2.2 自托管要求（换皮批施工项）

定稿评审包中 Noto Serif SC（600/700/900）与 JetBrains Mono（400/500/700）为 Google Fonts 在线加载——**施工期必须自托管**：woff2 子集化（中文按用字子集），字体文件入仓，首屏字体 display=swap，杜绝在线加载的闪字与离线白字。

### 3.4 机框与触件

- 设计基准 = 402×836 机框（iPhone 系），页面评估一律 390×844 实尺寸（UX harness）；
- 主触件命中 ≥44px（dock 钮 44、爪钮 58）；小触件下限：qadd 30、stepper 26、返回 36——**小于 44 的件必须有 ≥8px 的周边无冲突区**；
- 安全区：`env(safe-area-inset-*)` 套 calc()，dock/吸底 CTA 必须让位；底部弹层 = 抓握手柄 + 可点遮罩 + 滚动锁（三件套缺一是废件）。

## 十、换皮批验收尺（UX 视觉走查清单 · 逐屏过）

1. **点睛预算**：淡黄每屏 ≤2 处（含 dock 爪钮/选中态/环/角标）——超一处即打回；
2. **否决项**：每屏自问「本屏的活物是什么 / hero 在哪」——答不上=不进交付（21 号档修订入规）；
3. **四铁律**（14 号）：不画不存在的功能 / 不改交互步数 / 不丢功能入口 / 不为美观牺牲计时项；
4. **色纪律**：禁用色清单 grep = 0（#FDC830 / #D97B4A / 深绿 / 纯黑纯白底）；红线文案 grep = 0（返现/返钱/疯抢/秒杀/守护值/充值）；「年费≠储值·到期不自动续费」明面在位；
5. **工艺地板**：发丝线半透明染色（无硬实色线）/ 阴影染色（无纯黑影）/ 正文对比 ≥4.5:1 / 触件 ≥44（小件有安全区）；
6. **字纪律**：数字金额时间=mono / 屏题=serif / 正文=sans——三轨不串；mono 溯源行无折行孤字；
7. **实尺渲染**：390×844 真机或仿真逐屏截图，**对照眼睛不对照文字**（自检失实教训：检查通过≠设计成立）；
8. **状态栏真实时钟**；dock 让位安全区；弹层三件套（手柄/遮罩/滚动锁）；
9. **照片纪律**：拍摄清单五检（毛发/人手/文字/色温/网红脸），占位残留=0。

### 12.2 反对意见与风险

1. **本规范沉淀的是「客户端 1.0 这一屏语言」，不是「三端语言」**——员工端/商家端只有 §八 原则裁定，换皮批若夹带两端私货，验收尺管不到，届时以「未裁定不开工」拦；
2. **BANNER 槽是最大变数**：它是首屏视觉重量最大的面，而内容是素材通道的平面物料——若首批 BANNER 真件质量低于占位渐变的气质，首页会整体掉档。建议首批 BANNER 过 PM 验收 + 老板过目后再上线；
3. **字阶小字档在低端安卓机上可读性临界**——微印 7.5 仅限环心/圆点等装饰位（不承载信息）；信息性小字 8.5 一档，真机复走时如老板感觉小字糊，验收尺允许 8.5→9 全局抬一档（只抬 8.5 这一阶，不破体系）；
4. **素材替换有工期风险**：拍摄清单 13 组实拍若跟不上换皮批节奏，宁可带占位渐变上线也不带不达标的照片上线（素材死规 v2 优先级高于工期）。
