01 · DECONSTRUCTION · 母本：星巴克客户端（Mobbin 母本在库 ⑤ 组）

拆结构，不抄皮。

星巴克的皮（绿 / 九宫格 / 积分星）一寸不拿；星巴克的骨（会员体系如何长在 App 里）逐根拆走。以下七条位移进两版方向方案，四条禁令全程把守。

七条结构位移

星巴克怎么做 → Philia 怎么用（两版各自选型）
01
首屏 = 会员状态，不是营销场。星巴克打开第一眼永远是「我的星数 + 扫码」，营销让位。→ A 版直搬：身份带上楼。B 版转译：首屏给「它的状态」，会员状态退一格到第二张卡。
02
Scan to earn 大按钮。会员码是首屏常驻动作，到店即扫。→ 会员码必须有首屏落点：A=身份带右侧大钮；B=档案封卡下窄行。手持码态两版同构（扫码识别率是物理约束）。
03
星数进度条 + 规则一句话。「175★ · 每 9★ 兑 1 份」——积累可视，规则一行说清。→ 转译为回馈金结算环：「上月 26 日 ~ 本月 25 日 · 次月 5 日到账」+ 一句话「买商品的 10%，次月回到这里」。不搬积分制。
04
钻星身份大卡 + 权益图标墙。会员中心 = 一张身份卡 + 一面扫得完的权益墙。→ 会员页 = 卡面大卡 + 权益陈列。A 用图标墙（山姆同构）；B 用编号保障清单（档案语言）。
05
等级 = 身份物件。金星级卡面本身是设计品，卡面即身份。→ 四档四色卡面（冻结件）：档色即身份，一眼可辨。本稿只定卡的大小/状态/摆放，卡面艺术=23 号标准件槽位。
06
啡快 / 专星送双主入口。下单效率直给，两个动作吃掉首屏黄金区。→ A=预约洗护 / 预约寄养双入口大卡；B=单主钮「为它预约本周洗护」+ 文字链（安静口径）。
07
按天折算话术。山姆「0.72 元/天」同款降门槛公式。→ 沿用 V4 已过的「¥599 = 每天 ¥1.6」换算，两版同。

四条不抄

抄皮 = 死。每一条都有前案实锤。
✕1
不抄绿。Philia 色 = 深棕 / 纸白 / 淡黄 / 卡其（CJ-0921-12 冻结）。星巴克绿一像素不进稿。
✕2
不抄九宫格首页。前案实锤：照星巴克小程序首页（绿渐变幕 + 九宫格）做的宠物首页被判难看——病不在配色，在「首屏没有唯一焦点」。首屏焦点 = 一件有视觉重量的东西，不是图标阵。
✕3
不抄积分制。回馈金 = 现金返还账本（三本账物理分离，永不计营业额），不是游戏化积分。进度构件回答「钱什么时候到账」，不回答「攒星升级」。
✕4
不抄营销密度。零弹窗全线；一页最多一个营销卡；付费会员首屏永无开卡引导（运营位人群分屏规则不动）。

为什么是星巴克

因为星巴克证明了一件 Philia 最需要的事：会员体系可以是 App 的骨架，而不是 App 里的一张页。它的首屏、它的卡、它的码、它的进度条，全都围着「你是会员」这件事转——这正是山姆式年费底座在客户端该有的样子。

两版的分歧只剩一个：会员状态要不要直接占领首屏？A 说「要，那是星巴克的本事」；B 说「不，Philia 的首屏永远先给毛孩子，会员是它的保障，不是它的主角」。这个分歧交老板终审。
