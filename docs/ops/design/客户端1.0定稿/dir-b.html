会员卡怎么摆 · 方向 B 答案

装帧制：卡不抢戏，印在那里就够了。

首页不出现完整卡面——只有一枚档色蜡封小章。高端品牌的会员身份从不挂在门口，它印在档案封面。完整卡面只在会员页（装帧）与我的页（身份大卡）现身。

状态位置尺寸（390 宽）呈现
印章态首页档案封卡右上（B-1）46px 圆形档色蜡封只露印，不露卡。档位=封面上的那枚印，一眼知级别，零叫卖。
降级态首页服务中态（B-2）26px 小印 + 一行字LIVE 优先，会员信息收成「印 + 一行」，与 A 同纪律。
装帧态会员页（B-3）大卡全幅 + 四档装帧墙当前装帧大卡置顶；下方「四种装帧」竖排全宽条（档色样片 44×30 + 档名衬线 + 一句话主张）——像为档案选封面，不是比价做题。
账页态会员页卡下（B-3）全宽 −44 横条回馈金=这份档案的价值页：「今年已省 ¥486.20」mono 大数字承重。
手持态会员码屏 + 我的页（B-4）卡头 64px 档色 + 白卡墨码与 A 同构（扫码识别率是物理约束，两版不分叉）。
密度节奏 · 方向 B
屏密度节奏理由
首页常态松（4/10）宣言 + 一张大卡 + 一个按钮 + 一行文字链——首屏只有它，该松的松。
首页服务中态中（5/10）档案页卡 + 页码轨道承重，无痕语气（「证书和报告会来找你」）。
会员页中（5/10）卡 + 账 + 编号清单 + 装帧墙——仪器表的秩序，不是货架。
我的页松（4/10）同 A（冻结骨架），语气更静。
安心证书（签名时刻）最松（2/10）归档仪式：编号 + 蜡封 + 毕业照，全 App 最静的一屏。
