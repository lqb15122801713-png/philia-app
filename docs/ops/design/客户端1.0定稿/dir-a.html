会员卡怎么摆 · 方向 A 答案

三态制：卡永远在伸手可及的地方。

档色即身份（四档四色冻结，卡面=23 号标准件槽位，本稿只定摆放）。星巴克 Scan-to-earn 的转译：会员码是到店动作，必须常驻首屏。

状态位置尺寸（390 宽）呈现
在岗态首页深色身份带（A-1 · 终审保留件）全宽 −44 · 高 ~78px 横卡左：卡面缩略 64×42（档色槽位）；中：档名衬线 + 回馈金 mono；右：会员码纸白胶囊。整卡可点进会员页。
降级态首页服务中态（A-2）全宽 −44 · 高 40px 胶囊行服务中态 LIVE 优先，身份收成一行（档 + 余额 + 码入口），不抢进行中卡。
全身态会员页顶部（A-3）宽 320 · 高 204px 大卡，横滑 deck当前档居中全幅；其余三档两侧窥视（档色一眼可辨）；卡面=标准件槽位（蜡封 / 线稿 / LOGO 位标定）。
手持态会员码屏 + 我的页（A-4）卡头 64px 档色 + 白卡墨码扫码识别率是物理约束：码区白卡墨码不动，档色只做卡头。我的页身份大卡内置「出示会员码」条。
办理态会员办理页（未购用户）hero 大卡 + 权益墙 + 开通大卡山姆四段式：卡 → 账（一年最高可省 ¥X）→ 权益 → 行动「开通 · 每天 ¥1.6」。素材=A5 槽位。
