## 七、工程经验（本次实战沉淀，新窗口直接用）

1. **弹层挂 frame 层，不挂滚动容器内**（否则占滚动高度/渲染错位）；frame 需 overflow:hidden 裁剪；`.sheet.on` 用 `transform:translateY(0)` 不用 `none`；
2. **压叠布局的居中一律按可见区域算**：被遮部分计入该侧 padding（老板指出的"伪层级"坑）；
3. 截图目检纪律：Chromium 渲染→亲眼看→修复→复检；折行孤字（mono 溯源行）是高频瑕疵位；
4. 加购飞行小球=transform+transition 两段式（rAF 启帧），角标弹跳用 animation 重挂类名；
5. 状态栏时钟用真实时间（硬编码 9:41 是盗图感）；
6. 图片槽位 object-fit:cover + 固定高；素材先裁水印再压缩（≤1100 宽 q85）。

## 八、Skill 四件工作法（老板 2026-09-22 授权 · 限新设计窗）

> 来源：GitHub `mouse-lin` 仓四件（`finesse-skill`/`finesse-brief`/`frame-smith`/`finesse-term`）。仓是源头，本节为工作法封存——新窗口先按本节干活，深件按需回仓读 `references/*.md`。

### ① finesse-ui（UI Skill · 主力）

**定界**：四种 register——brand（设计即产品：landing/品牌页）/ product（仪表盘/后台/数据表）/ commerce（PDP/PLP/购物车/结帐）/ **h5（只活在手机里的页面——客户端三端就是它）**。h5 是容器：先锁机框，再裹一个内容 register（商城屏=h5+commerce，工作台=h5+product）。

**三档表盘**：SOUL（性格浓度）/ SPECTACLE（视觉引擎野心）/ DENSITY（密度）——产品态锁 SPECTACLE 低、DENSITY 高；h5 的 SPECTACLE 花在转场与家具上，不是 WebGL。

**工艺地板（两端通用，违反即廉价）**：中性色全部向品牌色温染色，禁用纯 #fff/#000；描边用半透明发丝线（深底 rgba(255,255,255,.07–.22) / 浅底 rgba(0,0,0,.06–.08)），禁用硬 #333 线；阴影染色不纯黑；正文对比 ≥4.5:1；一支强调色锁全屏（Philia 纪律=淡黄每屏 ≤2 处，更严，以我方为准）。

**h5 机框契约（本次陈列馆全套用它）**：`<meta viewport-fit=cover>`；body 锁死不滚、`#app` 才是唯一滚动容器；桌面预览=406px 机框+斜放投影+同色 bezel；安全区一律 `env(safe-area-inset-*)` 套 calc()；底部热区=拇指区（主行动沉底）；状态栏画真实时钟（硬编码 9:41=盗图感）；TabBar/dock 激活态=实心形状不是变色；底部弹层必备抓握手柄+可点遮罩+滚动锁；触件 ≥44px 命中区、`:active` 反馈、禁灰闪；入场编排 60–80ms 逐项错峰。

**反廉价黑名单（高频雷）**：em-dash 装饰 / 渐变文字 / 默认玻璃拟态 / 侧条卡片边 / AI 紫光 / 每节一个小眉标 / 01·02·03 编号当默认架构 / 六张一样的卡 / div 伪造截图 / 假精确数字 / 类目默认配色（宠物暖米+黄铜=饱和默认，须有名有姓地拒绝或超越）/ Inter·Fraunces 无脑默认 / 该有图的槽位空着。

**发散机制（出两版方案的机器）**：灵魂不选表，五轴组合（色结构/字体关系/布局家族/引擎/材质隐喻）；两版眯眼测试——各自能用一个具体名词命名（吧台 vs 档案夹），名同=同稿；Mode 2=做三个真稿让人用眼睛选，不给形容词菜单。

**预检**：先问"这页真的渲染了吗"（所有 href/src 有真文件），再过黑名单+手机地板+无障碍。

### ② finesse-brief（工作台架构师 · 定义层）

跑在 UI 之前，只答"这东西是什么"，不写界面。**五件按序造**：身份（谁的台子/围着什么转）→ 钩子（打开第一眼那行字）→ 数据地板（每个钩子字段：读哪个字段/谁写它/何时写/第一天空态说什么/断联日说什么——答不出五问不是钩子）→ 模块/频道 → 收入缝（从既有模块长出来，焦虑场景不挂广告）。
**三档表盘**：CADENCE（多久开一次）/ INPUT（人喂它多少）/ DEPTH（它回报多少）——**INPUT 必须 < DEPTH**，否则定义期就死了。
**结构分类不看受众**：cycle/ledger/state/runbook/feed/care/operation/pipeline/registry/console/monitor 十一构，主+副各一；每个结构有自己的死法（console 死于全绿墙没人看，registry 死于首日空库）。
**系统域三件套不可省**：subject（主对象）/ entities（数据模型+字段写者四选一：user·system·integration·derived）/ 每模块 L1→L2→L3 页面树。
用于：员工端/商家端工作台定义（搁置件启用时）。

### ③ frame-smith（视频审美动效 · 导演）

是导演不是渲染器：读 brief 定 register（cinematic 横屏 1920×1080·30fps·12–24s 纯视觉无旁白，收在字标上 / short 竖屏 1080×1920 抖音系，可带字幕口播，钩子必在前 1.5s）；**硬门禁**：无 hyperframe/remotion 运行时不开工（先查环境）。
方法：一支效果引擎做到 100%（不做三支 40%）→ 节拍时间线（H0…Hn，每拍一职责，末拍落地）→ 揭示编排（文字/元素的进出矢量变化、兄弟错峰、主角有专属动作；头号廉价=全片一起淡入）→ 声音设计（BGM 首尾淡入淡出+3–6 个 SFX 卡拍点，音画同帧=专业感第一杠杆）。
反廉价：禁 linear 缓动、禁全程 0.5s 等时、禁无预备/过冲、禁末帧僵死无收束、禁 top/left/width 动画（只动 transform/opacity）。
用于：生日视频（年度签名时刻）/品牌短片，排期靠后。

### ④ finesse-term（术语 Skill · 说法层）

每轮对话都过一遍：用户用大白话描述界面效果/故障时——**照常把活干完**，再顺手带出术语（大白话+术语+最常见的坑）。
三硬门禁：①每条术语必须能指着用户本轮原话说出哪几个字触发的，指不出就沉默；②H5 的坑成对出现必须一起说（吸底操作栏↔安全区、弹层↔滚动锁、输入框↔键盘顶起、图片↔宽高比占位、头尾固定↔滚动容器）；③结果在前术语在后，一次最多 1–3 条，用户表达已准确时不教学。
检索：`node scripts/term.mjs find --q "用户原话子句"`（本地 128 条库，零网络）。
用于：把老板的"这一片/那个条/凸起来"翻成可施工的准确需求，并在回执里自然带出术语。
