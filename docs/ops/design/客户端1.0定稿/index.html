DIRECTION A

会员吧台

THE CLUB COUNTER

星巴克正传：会员状态即首页。打开 App 第一眼=我是谁（档）、我攒了多少（回馈金）、我现在能干什么（扫码 / 预约）。商业效率骨架，首屏密、情绪页松。

首屏焦点　BANNER 色卡槽位 + 身份带 + 浮动大卡（层层相压） 卡的摆法　三态制：在岗横卡 / 全身大卡 / 手持码态 签名构件　回馈金结算环（星数进度条的 Philia 转译）
DIRECTION B

档案装帧

THE ARCHIVE

安心研究所正传 × 星巴克纪律：宠物状态即首页。打开 App 第一眼=它、它的档案。会员卡=这份档案的装帧级别——只露印，不叫卖。托付感骨架，全链路更静。

首屏焦点　档案封卡（它的大图 + 档色蜡封小章） 卡的摆法　装帧制：印章态 / 装帧墙 / 账页 / 手持码态 签名构件　档案页码轨道（七节点=档案页 ①~⑦）
