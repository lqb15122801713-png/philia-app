## 提炼（不下载也该拿到的精髓 · UX 总监目检笔记）

**同题四骨架（宠物洗护预约 · 同一信息量的四种解法，横评价值最高）**：
- **h5-nuzzle（奶油米+珊瑚橙）**：三条硬教训——① v1 照星巴克小程序首页（绿渐变幕+九宫格）被判难看，连改三版配色都救不回，病不在配色在「首屏没有唯一焦点」；② 深色浮起药丸 TabBar——整页最重一块色压在最底，浅色卡才立得住；③ 首屏只有一个焦点且是一件数据构件（九段爪印仪表），正圆实拍图+「圆图·标题·大数字·三小指标」骨架。两个坑：24px 画不清的概念交给文案；`<span>` 不写 display 会摊成全宽。
- **h5-lather（奶油底+暖橙）**：强调色语义写死——橙只表示「已攒到的/此刻能做的」，价格时长一律墨色。签名构件=泡泡水位（与品牌名绑定的剖面件，不照抄参考图）。
- **h5-puff（白底粉光晕）**：三色分工死规——黑=唯一主行动 / 粉黄渐变=进度 / 红=当前位置与客服。卡图必须对题，卡色可以不像参考图。
- **h5-plush（暖石底+深松绿）**：阴影只两级（1px 细线+极淡落影），新拟态的死因=卡底与页底色差太大退化成普通白卡。签名构件=唱机（唱臂角度=洗护进度，同一构件三处复用读同一份状态）。
- **共性**：每页只有一支强调色并写清它的语义；同题不同骨架=方向稿横评的正解形态。

**其他可用件**：h5-brew（移动电商 PDP 教科书：加购小球抛物线+角标弹跳、SKU 联动、吸底购买栏——商城精巧件的出处）；h5-vigor（半圆刻度仪表=一根根短线不是 conic-gradient）；h5-azure（软不是靠 blur 大，是靠阴影颜色带蓝）；h5-nocturne/glow（工作台两体：夜航琥珀泛光/肌律 11 段圆弧仪表）；web 包 zolo/lumina（桌面品牌页工艺参照）。

**使用纪律**：模板仅供参考，不抄皮不搬结构；图片素材为 Unsplash 演示件，正式产品一律换自有素材（原包 README 明示）。
