> **用途**：客户端 1.0 定稿中的 13 件占位素材（AI 生成，素材死规 v2 全过）全部只是原型期占位——**施工期按本清单换成三店真实照片+真实数据**（22 号档纪律延续）。
> **依据**：《设计规范 v2.0》§七槽位规则 + 定稿 `assets/素材清单.md`（13 件占位件在案）。

## 一、总纪律（素材死规 v2，逐件过检才入库）

1. 不带文字/标语入镜（包装字、价签、屏幕字=废件）；
2. 不拍人手为主的特写（畸变高危；洗护师操作画面只拍「手+毛」的局部关系，不以手为主体）；
3. 不要通用可爱插画感——全部真实摄影；
4. 不摆拍合影（多宠=日常画面抓拍）；
5. 无 AI 网红脸宠物（过度大眼/过度磨皮/卡通化=废件）；
6. 色温统一 sepia 暖调（与三色纪律同温：不偏冷、不偏品红）；
7. AI 生成水印一律裁除（占位期已执行，实拍期天然无此问题）。

**验收五检**：毛发质感不穿帮 / 人手不畸变 / 无乱码文字 / 暖调同温 / 无网红脸——五检任一不过=废件重拍。

## 二、技术规格

| 项 | 规格 |
|---|---|
| 尺寸 | 长边 ≤1100px（卡位图）/ 1600px（hero 与证书 BA 图） |
| 比例 | 按槽位：方图 1:1（相册/节点格）· 横图 3:2 或 16:10（hero/案例流/房型）· 竖图 4:5（肖像卡） |
| 格式 | JPG q85（或 WebP 同等质量），单件 ≤200KB |
| 命名 | `场景-对象-序号.jpg`（如 `xihu-jinmao-01.jpg`），入仓 `assets/` 对应目录 |
| 拍摄 | 手机即可（近三代旗舰）；自然光优先，窗边/午后光最佳；禁闪光灯直打 |

## 四、执行与验收流

1. 店长按本清单拍 → 每店每组 ≥3 张候选 → 传产品侧汇总；
2. PM 初筛（数量/规格/明显废件）→ UX 五检终审（死规 v2 + 色温）；
3. 过检件压缩入库（≤200KB）→ 换皮批施工时替换占位件；
4. **工期纪律**：实拍跟不上时，宁可带占位渐变/色块上线，也不带不达标照片上线（规范 §12.2 风险④）。
