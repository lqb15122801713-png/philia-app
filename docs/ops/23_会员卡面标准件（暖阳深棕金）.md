## 一、六维解构（复刻规格·存档备查）

1. **卡面**：深棕磨砂哑光大卡（深棕墨族 #2E2318~#3B2E24），圆角+四角细金内框线，皮纹/磨砂质感，拒绝亮面塑料感；
2. **字**：淡金/香槟金文字——「暖阳会员」衬线中文大标、「¥599/年」大数字、「含 3 只毛孩子 · 都被叫得出名字」主张行（共创会落槌口径一字不动）；
3. **LOGO**：左上 PHILIA＋Love·Bond·Life（淡金），心形宠物标（VI 冻结件用法）；
4. **签名件**：右上**淡金爪印蜡封**（立体金属蜡封、浮雕爪印）——品牌独占语言，每档必有；
5. **右下**：**蓝图线稿金毛**（仪器制图画法：虚线辅助线+比例尺，淡金线）——安心研究所独占语言延续；
6. **气质**：贵、静、暖——高端会员卡逻辑（山姆/黑卡参照），零营销词、零电商腔、拒绝通用可爱。
