## 〇、批次定位与两个概念划清（全批的纲）

**退款 ≠ 反结账**，两通道并存、口径分清、互不借用：
| | 反结账（既有，不动） | **退款（本批新建）** |
|---|---|---|
| 性质 | 错单纠正（店主冲正） | 客户侧真实退款（经营行为） |
| 发起 | 仅店主 | 店长（手机上批）/店主 |
| 钱口径 | **不计当日已收**（冲正关联单） | **计退款列**（当日经营流水负向单列，日结"退款单列"——APP-40 口径） |
| 账呈现 | 原单灰签+冲正关联单双向可查 | 原单永存+退款单关联双向可查，原单状态→已退款（部分退款→部分退款） |
| 库存/储值/次卡 | 自动回补（既有） | 自动回补（本批同款，走 stock_movements 流水） |

**边界（写死）**：①不动反结账既有逻辑；②年费会员退卡/回馈金清零=R11 会员批；③线上支付通道未接入——实退动作=**内测期线下原路退回+系统内"实退完成"标记**（通道期换装 API 自动退，接口预留）；④储值退款=退回储值账户（余额回补留痕），不退现金（三本账口径）；⑤UI 工艺件自装；⑥【V5】**已冲正/已撤单=无退款入口**（页面不显示+server 明文拒"原单已冲正/已撤，不可退款"——冲正与撤单已是终态，再退即双冲）。

## 一、红线与硬约束（验收一票否决）

| # | 红线 | 写死方式 |
|---|---|---|
| 1 | **全链路真生效，禁止第三态**（补丁②） | 退款确认=同事务六联动（退款单/支付段回补/库存回补/储值次卡回补/财务口径/回馈金扣回列位），任一失败整体回滚；禁止"点了留痕钱账没动" |
| 2 | 原单永存不涂改 | 原单仅挂退款关联标记（refund_status/refund_bill_no），内容一字不改 |
| 3 | 强制原因+留痕 | 发起必填原因；谁发起/谁审批/何时/前后值全留痕（eventOutbox+refunds 表） |
| 4 | 权限闸门【V1 累计校验】 | 店员无入口（403/不可见）；**店长可执行**（本店）；**阈值按"原单累计退款额"校验**：该原单已退累计+本次申请>阈值（默认 ¥500，配置端口可调）即须店主——**堵拆分绕过**（拆三笔 ¥400 也累计成 ¥1200，直接顶到店主）；【运营加固】**凡涉储值退款一律店主批、不设阈值**（储值=负债科目：储值支付段退款/次卡退卡折算退储值，两类一律店主执行） |
| 5 | 退款不抹账【V2 现金段净额+V7 跨日口径】 | 已收不涂改，退款额**单列**；**日结现金物理对账=现金段净额**（现金已收−现金退款，微信/支付宝/储值/次卡各段同法分列）；【V7】**跨日退款计入"退款发生日"日结**（refund_bills.biz_date=执行日；不回填已冻结的历史日结——那天已经封箱，谁的钱哪天走账清清楚楚） |
| 6 | 提成冲减联动【V6 按比例】 | 全额退=该单提成全额冲减；**部分退款=按退款比例冲减**（该行提成×退款比例，精确到分）；已快照月份不动，差额进当月"调整项"（V1.3 口径） |
| 7 | **回馈金扣回联动（第六联动·接口冻结）**【运营加固】 | **退商品单必须扣回已发回馈金**：扣回额=该单已发回馈金×（退款商品金额÷该单商品总额），1:1 扣减留痕（前后余额+关联退款单号）；余额不足扣为 0 不负账，差额记"未扣回"不追债不惊扰客户；**回馈金未上线（R11）——本批冻结规则+refund_bills 快照 JSON 列位（rebate_clawback_fen 默认 0），R11 生效按冻结规则回归验收** |
| 8 | 幂等 | 同单一退款申请重复提交=返回现状；部分退款累计不得超过原单可退余额 |

## 二、退款场景全覆盖（六类，逐类口径）

1. **未支付单**：不涉及钱——沿用既有撤单（clerk 可撤，补丁①），不在本批；
2. **已支付单全额退款**：全额原路退回；支付段逐段回补（现金段→退现金标记；微信/支付宝段→线下原路+实退标记；**储值段→余额回补**（前后余额留痕）；**次卡段→次数回补**（pass_deduct_logs 正向行+note 关联））；商品行→库存回补（stock_movements source='refund'）；预约行→paid_at/paid_fen 清零回待收款口径（已核销/已服务→禁止退款，转店主特批）；
3. **已支付单部分退款（按行/按金额）**：按行退=该行全联动；**按金额退=按支付段占比同比例回补**【V3】（组合支付拆段：现金 60%/储值 40%→退款额 6:4 分摊回补各段，分摊明细页面明示）；
4. **预约未到店退款（已支付未服务）**：预约取消+已收款退款二连（既有取消流+本批退款链接入）；
5. **寄养按晚单部分退（提前接回）**【V4】：按剩余晚数退——剩余晚数×晚单价，支付段占比同比例回补（同 V3）；已发生晚数一分不退（页面分段明示"已住 N 晚不退/剩余 M 晚可退 ¥X"）；
6. **次卡退卡**【V8 付费次数口径】：折算=**剩余付费次数×（实付金额÷付费总次数）**——**赠次不退现金价值**（赠送次数退款即作废、不计价、页面明示"赠次 N 次随退作废"）；退到储值账户或线下原路（二选一必选+留痕）；**退卡后卡作废留痕**。

## 三、流程与状态机

发起（店长视图/商家端：选单（已冲正/已撤单无入口·V5）→选类型（全额/按行/按金额/寄养剩余晚/退卡）→填原因→预览联动清单（退什么钱/补什么货/回什么余额/扣什么回馈金列位，**明示六联动**）→重确认 D 套）→执行（同事务六联动）→退款单（refund_bills：单号 RB-yyyymmdd-NNN、biz_date=执行日（V7）、关联原单、类型、金额、原因、操作人、审批人、实退方式、实退标记）→实退登记（内测期：线下退完后点"实退完成"+备注；超 24h 未登记进店长待办提醒）→**当日**日结"退款单列"自动汇入（V7）。
状态机：draft→executed（账已联动）→settled（实退完成）；店长可驳回 draft（驳回留痕）；**executed 后不可撤销**（要纠错=再开一笔正单，不许反向涂改）。

## 五、页面与口径（体验关五条随批）

- 收银台流水行：已退款单灰签+"退款 ¥X"红字标签，点开见退款单关联（双向可查）；已冲正/已撤单**无退款按钮**（V5）；
- 店长视图新增"退款审批/实退待办"区块（既有七区块加一）；
- 日结页：退款单列（笔数+金额）+**现金段净额**（V2），当日净额=已收−退款；财务页同口径；历史日结封箱不回填（V7）；
- 部分退页面：已退累计/可退余额/本次分摊明细（V3）三行明示；
- 文案软性口径：客户侧不暴露内部词（"退款已安排，按原路退回"）。
