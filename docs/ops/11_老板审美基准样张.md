# 老板审美基准样张（V1）

> 来源：老板 2026-09-21 确认——产品侧《客户端 12 屏·v9 瑞幸式大卡首页（v9.1 全览）》为**目前做得最好的 UI**，立为审美基准。
> 样张原件：《客户端全屏试样-v9.1-全览.png》（老板持有，设计窗口开工时由老板直接发送；仓内引用件待补传）。
> 本文件发给谁：UX 设计总监（方向稿自检对照）> 全窗口（终审标准对齐）。
> 规则：**方向稿与一切 UI 产出只能高于它，不能低于它；低于它=不到终审线，不必呈老板。**

## 一、这版为什么好（老板感觉的六条设计语言翻译）

1. **金只点睛，不糊墙**：奶油暖黄骨架（F6F1E3），柠檬黄每屏仅一处主行动+dock 中央钮。对治 9-18 诊断①"大面积亮黄=外卖感"——黄从"墙"退成了"珠宝"。
2. **有编辑感**：登录页衬线宣言"守护每一次被照顾的时刻"，安静、贵、像杂志封面，不像工具启动页。
3. **真实摄影+定制插画混搭**：大幅法斗实拍建立情绪，手绘插画图标建立品牌私有语言——没有"全网通用组件感"。
4. **密度有节奏**：首页大卡横排三入口（瑞幸/星巴克式商业效率）与"我的"页亚朵式安静卡（高端留白）并存——该密的密，该松的松。
5. **有情绪场**：philia 页"旺财的崽"养成互动——签名时刻候选，值得截图的那类屏。
6. **带着工程纪律的设计**：跨屏一致性矩阵（页边距 22/卡距 12/圆角四档/字阶五档）、色板冻结零改动、每屏锚定 Mobbin 真实标杆（Starbucks/Glovo/Vestiaire/Noom…）——好看且可施工，不是飞机稿。

## 二、覆盖范围与缺口

- ✅ **客户端**：12 屏全览（登录/首页双态/预约单屏/服务全程/philia 页/商城/详情/订单/我的/宠物档案/空态）+ dock 两案对照。
- 🔴 **员工端、商家端：无同水准基准**。现存 9-17 U2 员工端（时间轴台 B′）、U3 商家端（墨轨案 A）未被老板点名为"最好"——方向稿期不得将其默认为基准延伸。
- ⚠️ 注意点：三端不是各美各的，而是**一个品牌三种密度**——客户端=情绪密度（脸），员工端=效率密度（手），商家端=信息密度（脑）。UX 总监方向稿须给出三端统一的品牌语言裁定，而非把客户端样式直接搬去工具端。

## 三、使用规则（入 UX 自检清单）

1. 方向稿每案出稿前：对照本样张逐条过第一节六条——缺一条，自检不通过。
2. 老板圈选 dock 案 A/案 B 后：圈选结果记本文件，冻结为三端 dock 唯一形态。
3. 本基准可被超越：若方向稿某案老板判定"比 v9.1 更好"，则替换样张并记版本（V2）。

## 四、口径注记（2026-09-21 补）

- **"守护值"概念已废止**（v9.2 口径：不建第四本账——老板裁定"数据层 UI 层分开"+运营审美打回四条）：样张中"守护值 320/守护账户条"等元素仅作版式参照，换皮批将按文字口径注记表移除；基准效力在"设计语言六条"，不在该文案元素。
- 四档命名/价格按 CJ-0921-09（双源对账后正式解冻），样张中的占位档名（星芽/GUARDIAN CARD）不作依据。
- **方向稿动态（CJ-0921-10）**：老板倾向方向三「安心研究所」（"跨时代"），钦定三色=**深棕/卡其/淡黄**（亮柠檬黄与深绿退场）。方向三垂类化调整确认定稿后，**替换本样张为 V2 基准**；v9.1 六条特征继续作为自检底色（金只点睛/编辑感/摄影插画混搭/密度节奏/情绪场/工程纪律），其中"柠檬黄点睛"按三色裁定修订为"淡黄点睛"。
