## 一、总则（两端共同纪律 · 单 token 源）

1. **token 全引 34 号档 §一**（纸白 #FAF8F2 / 白卡 / 深棕墨 #3B2E24 / 深棕 #2E2318 / 淡黄 #F2DFA6 / 淡金 #E8CF8C / 卡其 #B9A482 / 暖灰 #8A7D6B / 发丝线 .14/.08 / 赭红 #B4502E），零新色零新字体；禁用色清单 grep=0（F2 柠檬黄处置见 UX-01）。
2. **字三轨**：serif 仅页题/报头（屏题 27/900 手机、29/900 桌面）；sans 正文执行；mono 加重（时刻/单号/金额/状态/溯源行 9–9.5）。
3. **淡黄 = 「此刻要做的」写死语义**（两端主行动唯一强调色，每屏 ≤2 处，含 dock 激活短划/当前节点/主钮）；**赭红仅异常**（审批待办/差异红字/超期预警），不作装饰。
4. **导航冻结**：员工端 dock=平铺条四槽「工位 / 预约 / 打卡 / 我的」（爪印=客户端私有，两端不用；激活=顶部淡黄短划）；商家端手机 dock 五槽「总览 / 门店 / 收银 / 报表 / 我的」；**商家端桌面 wnav=十五口冻结（老板 9-27 拍）：经营（总览·驾驶舱 / 门店端·预约 / 寄养 / 收银台 / 日结 / 退款）· 商城（商城订单 / 商品 / 会员·次卡）· 管理（员工 / 审批中心 / 监控 Hub / 报表 / 权限矩阵 / 门店档案·设置）+ foot 开发者管理端**；控制台无 dock 无 BANNER（共构不分叉）。
5. **二级页制**：返回条 backbar（白卡圆钮 ‹ + 题 + mono 注），无 dock；吸底主行动=渐出底 + btn-action。
6. 页边距：员工端 16–22（pad 22 沿用定稿）；桌面主区 22/28。圆角/阴影谱系沿用 34 号档 §三。
7. 状态栏真实时钟（禁硬编码 9:41）；触件 ≥44px；零弹窗（唯一层叠件=底部弹层三件套）。
8. 四铁律：不画不存在的功能 / 不改交互步数（六步/拍照≤2击/打卡≤2击原样）/ 不丢功能入口（三级视界留位）/ 不为美观牺牲计时项。
