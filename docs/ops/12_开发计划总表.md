## 四、施工发起流程（2026-09-21 老板要求界定，项目经理定版）

```
① 任务书：产品侧起草 → 运营过稿（攻防）→ 修订出冻结版 MD 推仓（docs/ops/ 编号文件）
② 老板会签授权（对冻结版+配套件，一句话留痕入台账 CJ 编号）
③ 项目经理开工确认信（一句话发令枪：验收通过+开工时间）
④ 产品侧下施工令（MD 级施工指挥文件：基线分支/施工红线/闸门/流程/心跳）
⑤ K3 施工 → 闸门全绿 → 七步复核 → 老板书面授权合并 → 部署 → 三方分尺复走 → 双签闭环
```

**原则：发令枪一句话，弹药全是 MD。**
- 没有冻结 MD（①）不许施工——铁律不变；
- 开工确认信（③）只是"验收通过"的调度信号，**不替代、也不简化任何施工文件**；
- 施工令（④）必须是 MD 级正式文件（照 R12 样板：红线逐条/闸门清单/分支与 evidence/60 分钟心跳/PR 只开不合）；
- 一句话能解决的只有"发令"，一句话解决不了的一律走文件。
