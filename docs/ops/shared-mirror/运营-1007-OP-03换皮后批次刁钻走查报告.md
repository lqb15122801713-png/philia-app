## 二、缺陷清单（分级+改进方向）

### P1（裁定口径级）

- **P1-1 注册即会员未兑现**（CJ-1007-01③）：自助开户落成 users 档案即登录成功，但微光档不落——开户与开档仍是两段动作。改进：开户事务内连带 openFree 落档（或首页首进懒落档），裁定怎么写就怎么落。
- **P1-2 权益表「寄养折扣」同档两值**（10-02 报告 P1-2 升级证据）：开通页微光档=「寄养折扣：门市价」，会员中心微光档=「寄养折扣：9 折」——同档同项两个说法，且 27 号档冻结参数本无寄养折扣项。改进：权益模板回读档位配置单一事实源；该权益项去留须裁定（撤文案 or 补裁定落地）。

### P2

- **P2-1 驾驶舱同页「待办合计」两值**：连锁视图卡=0，晨报卡=12（同页同指标）。
- **P2-2 安心包要货口未收净**：三件已下架（off）安心包仍出现在调拨要货的商品下拉——售卖口收了、要货口没收。改进：要货/调拨商品源同排除 care_package（与收银台选购同闸）。
- **P2-3 营销页端口 key 裸露**：叠加规则区显示「none优惠券不与会员折扣叠加…coupon_stack_rule」——英文键名+none 前缀粘连中文，店主看不懂。改进：key 收进注释/ Tooltip，公示只留人话。
- **P2-4 端口编辑「假保存」陷阱**：改字后点「保存变更」弹复核层，漏点「确认保存」=静默未落库、页面却显示新值（无提示）。本人连续两次踩中。改进：编辑态离开拦截（有未确认变更提示）或按钮状态明示「未确认」。
