## 件 1 · 联合支付（QA40-B6-01，P0）——收银台

**操作三步**：
1. 收银台开一单（任意商品，如 ¥129 犬粮）→ 进支付面板；
2. **现金栏手输改成 64**（小于应收）→ 停 3 秒看画面；
3. 把现金栏改回补足（或按提示补到齐）→ 确认结账。

**拍什么**：手输 64 后的画面（重点看：①顶部「应收」大字**仍是 ¥129 没变**；②明细行写的是「现金承担」不是「应收」；③差额提示「还差 ¥X」；④确认钮锁死点不动）→ 补足后放行结账的画面 → 结完的单据页。

**QA 看什么**：三处数字同源不打架、应收永不被手输改动、不足不放行、补足才放行。

---

## 件 2 · 分摊页面（QA40-D1-02，P1）——商家端

**操作三步**：
1. 打开**日结页** → 截屏；
2. 打开** dashboard（看板）首页** → 截屏；
3. 对照收银台头部今日营业额数字。

**拍什么**：日结页（要有「**会员费分摊确认（本月累计）**」一行+金额）→ dashboard 营业额卡（要有口径注小字）→ 收银台头部（三处营业额主数应一致）。

**QA 看什么**：分摊行在+数字精确到分+分摊**不计入**已收合计+三页同数不破。
⚠️ **提醒：分摊数字比 9-23 那次小是口径修正（改成本店口径），不是 bug，不用报。**

---

## 件 3 · 自助注册（QA40-A1-01+A1-02，P0 主流程）——客户端

**操作三步**：
1. 客户端登录页输内测口令 → 出现**手机号输入卡**（「首次使用将自动注册」）→ 输一个**全新手机号**进系统——**顺手掐表**：从输完手机号点确认，到进首页，几秒（测 3 次记 3 个数，可换三个新号）；
2. 退出，用**同一个手机号**再进一次 → 应直接登录、**不再注册**（不出现第二个会员档）；
3. 试试**乱输**（不填手机号/乱打几位）→ 应有明确提示，不白屏不卡死。

**拍什么**：手机号输入卡页面 → 注册成功进首页的画面+3 次读数（写在纸上拍进来也行）→ 同号二次进入的画面 → 乱输提示的画面。

**QA 看什么**：注册 ≤30 秒（3 次都过线）+ 幂等不双开 + 异常有提示。

## 件 4（顺带）· 登录提示（QA40-D8，P2）——登录页

**操作一步**：登录页**故意输错口令**（或不输直接进）→ 看提示。

**拍什么**：提示页面一张——应说**口令**的事（「口令不对/请输入口令」类），**不再说「server 已启动」**。
