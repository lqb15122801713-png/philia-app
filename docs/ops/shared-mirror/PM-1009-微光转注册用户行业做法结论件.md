# PM-1009-微光转注册用户·行业做法结论件（老板令：别人怎么做我们就怎么做）

> 调研源：freemium 体系行业实践（RevenueCat 免费层设计指南/丝芙兰积分制/Costco-山姆订阅制对照/会员体系拆解多篇）。2026-10-09。

## 行业怎么做（多源一致）

1. **身份零门槛**：注册即身份，不设有效期、不设数量限制、不设审批——丝芙兰粉卡「注册即是会员」同款；免费层要「真能用」（RevenueCat：真价值永久免费，不做残废版）；
2. **限制只设在权益/用量上，不设在人头上**：免费层限制=折扣无/回馈金无/专属服务无——不是「你只能养 3 只」这种身份限制；
3. **升级靠价值触发不靠卡脖子**：付费档=折扣+回馈金+专属权益（锦上添花型，Prime/88VIP 式），用户因为「值」升级，不是因为「被限得难受」；
4. **权益阶梯单向上升**：档越高权益只增不减，降级不吵。

## 落到我们（微光→注册用户口径）

- 注册用户=注册即得身份，无有效期、宠物数量不限、无办理动作；
- 注册用户权益=能预约/能消费/有台账（系统正常使用全通）；
- 付费档（萤火/暖阳…）=折扣+回馈金+专属权益层叠加上去；
- 唯一要你单独点头的一件（涉钱纲领③）：**安心包全员免费（9-22 你定的）对注册用户是否延续**——行业做法=安心包这种「信任件」建议全员延续（它本来就是零成本好感件）。
