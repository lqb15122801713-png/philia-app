## 一、骨架（自上而下）

1. **顶栏**：门店定位/切换（瑞幸同款）+消息铃；
2. **Banner 槽位**（画布端口可换）：活动/新店/回馈金卖点；
3. **核心动作区**（瑞幸式大入口，点进来精准找到需求）：**预约洗护｜寄养｜商城**三键；
4. **我的毛孩子卡**（Philia 灵魂件）：宠物头像+名字+「距上次洗护 23 天」+生日倒计时——第一眼=被记住；
5. **瀑布流案例**（小红书式双列）：美容师作品+客户反馈+门店日常——获客素材+信任证据；
6. **回馈金透出卡**：「我的回馈金 ¥XX·下次能抵」——划算感常驻；
7. **底 Tab**：首页/预约/商城/我的。
