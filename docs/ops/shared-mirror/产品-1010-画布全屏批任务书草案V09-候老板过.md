## 〇、这批干完你能干什么（人话先行）

**打开控制台画布端口，Philia 客户端的每一个页面都能点开看真样子、点哪块改哪块**——不只是一三个页面：我的、商城、预约、寄养、开通会员、会员中心……全部页面都进画布。而且「权益墙」（开通页/会员中心里那排「多宠覆盖·服务折扣·回馈金·专属洗护师」格子）里的内容也能直接改——改文字、改说法、换顺序，不用找工程师。

## 一、范围（两股，一次冻结）

### A 股 · 全屏入册（老板原话=全量，不许收窄）

- 客户端**全部主屏**入画布注册表：我的/商城首页/商品详情/购物车/预约洗护/预约寄养/开通会员/会员中心/回馈金账本/宠物档案/服务相册/消息/消费记录/协议中心/设置族——**屏数全量以片 0 盘点清单为准**（客户端路由逐屏过，一屏不漏；纯流程页（支付态/表单提交中）=盘点判定可不入，判定理由逐件写明候裁）；
- 每屏工艺照既有三屏同族：区块注册+预览 iframe 探针+点选反查+显隐/排序/文案点改+发布两步流；
- 会员态页预览=示例客户视图（微光正名批工艺，全屏通用化）。

### B 股 · 权益墙数据区块可改（PM-1010 钉的真缺口）

- 权益项（多宠覆盖/服务折扣/回馈金/专属洗护师/生日礼遇/皮毛检测/年度档案等）=**数据区块**入画布：改名称/改一句描述/换图标/调顺序——不只是改标题；
- 数值类（折扣几折/回馈金几%/含几只）=读档位参数透出，画布上可点跳「会员档」端口改数（区块内容=文案件，数值=参数件，两面都通）。

### 核销不施工

首页/会员中心/收银营销位三屏已画布化（在跑）——本批=扩全屏+权益墙，不重建三屏。

## 二、用户旅程（V2·Given-When-Then）

**旅程 1 · 老板改任意一屏（P1）**
- Given 老板开画布端口选「我的」页，When 点「宠物档案」卡片改文案为「毛孩子档案」并发布，Then 客户端我的页该卡片文案即时生效——零代码零部署；
- Given 画布选「商城首页」，When 拖拽把「新品区」移到「热销区」上方并发布，Then 客户端商城页区块顺序即时变。

**旅程 2 · 老板改权益墙（P1）**
- Given 画布开通会员页，When 点权益墙「生日礼遇」格改描述为「生日当月送洗护 9 折券」保存发布，Then 客户端开通页/会员中心权益墙同帧生效。

**旅程 3 · 店主预览会员态页（P2）**
- Given 任意会员态屏（回馈金账本等），When 画布打开，Then 预览=示例客户视图（带「预览示例」水印）全渲染。

- SC-001：客户端主屏入册覆盖率 100%（片 0 清单逐屏过，不入的逐件写明理由）；

## 四、两问闸（答死）

1. 后期谁管：屏注册表=写死件白名单（军规：区块注册表写死）；布局/文案/权益描述=端口留口（店主自管）；施工=A 窗；
2. 写死还是留口：区块类型注册表写死；每屏区块序列/显隐/文案/权益描述=画布端口数据（版本化+两步流照既有工艺）。

## 五、开口项（候老板裁）

1. **全屏节奏**：全量约 20+ 主屏，一批全吃=批大——我建议分两片扩（片 2=高频五屏：我的/商城/预约洗护/预约寄养/开通会员；片 3=剩余屏扫尾），你要一把全上也可（批拉长一天量级）；
2. **流程页入不入**：支付状态/确认订单这类「过路页」建议不入画布（改它们风险大于收益），你点头即按此。

1. 最大风险=全屏入册工程量大面广，区块切分粒度不一易返工——对策=片 0 盘点先定每屏区块清单候裁再动手；
