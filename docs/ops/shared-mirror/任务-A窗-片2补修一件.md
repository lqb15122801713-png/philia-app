## 缺陷（P1，打回唯一件）

**首页回馈金环期次窗口算错（HomePage.tsx `periodWindow`）**——付费档会员在每月 **26~31 日**看到：期次文案停留上一期（如 9-29 显示「周期 8.26 – 9.25 · 10 月 5 日到账」，正确应为「周期 9.26 – 10.25 · 11 月 5 日到账」）+ 环百分比被钳到 100%（正确 ≈10%）。

根因：三元两分支写成同一值——

```ts
// 现状（错）：inNext 分支与 else 分支相同，start 恒为上月 26
const start = new Date(y, m - 1, 26)
const end = inNext ? new Date(y, m, 25) : new Date(y, m, 25)

// 修法（对）：
const start = inNext ? new Date(y, m, 26) : new Date(y, m - 1, 26)
const end = inNext ? new Date(y, m + 1, 25) : new Date(y, m, 25)
```

附带一处一并核：`arrive` 取的是 end 次月 1 日，但展示只用其月份+settlementDay 日——修完确认「{arrive 月} 月 {settlementDay} 日到账」在 26~31 日窗口下=次次月 settlementDay 日（例：9-29 → 11 月 5 日）。
