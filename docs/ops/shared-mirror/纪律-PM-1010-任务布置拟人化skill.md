# 拟人化任务布置（老板 10-10 令：布置任务时就拟人化）

> 根因事故：画布「首吃三屏」——产品侧任务书自定范围收窄，老板要的是全屏可控。布置任务不拟人化=意图没对齐=返工。

## 五条死规

1. **开头一段人话**：这批干完，老板/客户在界面上能看到什么、能干什么不一样的事——不许出现技术词；
2. **每条任务=「你能在 XX 页面看到/点到 XX」**格式，不堆实现名词；
3. **范围从老板意图出发**：他原话要控制什么=全量列出，**不许自己收窄**；要收窄必须写明「我建议先 N 屏，因为…」并候他裁；
4. **技术词对照表**：必须出现时挂人话注脚（端口=后台可调开关；mock=演示假支付；域=一块功能）；
5. **交付前自检**：假想老板读一遍——他能不能不看代码就复述这批要干什么？不能=重写。

## 自检口诀
「老板读得懂吗？他点得到吗？我收窄了吗？」
