## 二、用户旅程（V2·Given-When-Then）

**旅程 1 · 客户商城线上付款（P1）**
- Given 客户购物车结算，When 确认订单去支付，Then mock 收银台四态可演，支付成功=订单 paid+核销码/明细全落；
- Given 付款后页面崩溃（掉单），When 重进「付了没开」，Then 自助对账补兑付，不重复扣款不重复发货。

**旅程 2 · 客户线上续费（P1）**
- Given 付费档临期，When 会员中心点续费，Then 续费确认页金额=server 实算（当前档价+多宠附加），mock 支付成交=到期顺延+回馈金解冻。

**旅程 3 · 店主切换通道（P2，资质到位后真用）**
- Given 资质三件到位，When 店主在端口填商户号/密钥（口令复核）+切真通道，Then 新单走真通道、在途 mock 单不受影响、kill switch 可瞬时回落。
