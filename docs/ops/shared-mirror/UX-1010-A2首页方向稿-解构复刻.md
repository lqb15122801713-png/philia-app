## 一、解构复刻映射（谁家手法 → 落在哪个件）

| 来源 | 拆出来的手法 | A-2 落点 |
|---|---|---|
| 瑞幸 | 「下单+领券」双瓷片=最高频动作绑最短路径 | 顶层双大卡（不动区）= Philia 的「下单」；回馈金=Philia 的「领券」，故五处透出围绕它织 |
| 瑞幸 | 灰底白卡列表区，版式绝对统一压住无限流 | 瀑布流卡版式锁死：封面+标题≤2 行+宠物名+点赞，信息结构恒定 |
| 瑞幸 | 单条横幅=同一时间只推一个活动 | 全首页唯一促销件=回馈金加速周横幅（卖点主承载），不新增第二促销件 |
| 星巴克 | 会员仪表盘：余额+进度+到账日常驻首屏 | 身份条+回馈金环（62% 本周期）不动；环行加「再约预计 +¥9.8」=星巴克「差几颗星升级」钩子的 Philia 版 |
| 星巴克 | 会员/玩法收 Tab，首页不留玩法楼层 | 负面清单照守：无金刚区、无会员玩法楼层、无第二促销件 |
| 小红书 | 双列不等高瀑布流，封面主导，用户用「选封面」暴露兴趣 | 案例流改真瀑布流：双列 8 卡不等高错落，封面图占比 ≥60%，标题≤2 行 |
| 小红书 | 笔记卡底行=作者+点赞（社交证明轻量化） | 卡底行=宠物名·品种（左）+ ♥ 点赞数（右），点赞是唯一互动件 |
| 小红书 | 商业组件先伪装成内容 | 回馈金透出全部做成「信息性透出」（算账数字），流内零 CTA |
| Rover（辅证） | 照片=信任货币，履约证明即种草素材 | 每张案例卡封面左上角 mono 小 chip 标服务类型（深层洗护/寄养日报/造型精修…），明示「这是真服务记录」 |

## 二、回馈金卖点透出五处（零新楼层、零新促销件，全是既有件的算账式加强）

| # | 位置 | 透出 | 逻辑 |
|---|---|---|---|
| 1 | 回馈金环行（megacard） | 「再约预计 **+¥9.8**」 | 星巴克进度钩：给出下一个具体可得，勾复购 |
| 2 | 再约状态条 | 「上单已返 **¥8.5**」 | 瑞幸「领券」逻辑前置：再约前先看到上次得了多少 |
| 3 | 单条活动横幅（唯一促销件） | 「洗护返 **1.5 倍**回馈金 · 预约抢翻倍 ›」 | 卖点主承载位；千人千面槽（新客可换首单礼） |
| 4 | 横滑商品卡 | 价旁「· 返 **¥6.5**」具体金额 | 山姆算账式：每件商品标返额，「值」感落到货架 |
| 5 | 一行账本 | 「本月已返 **¥86.40**」 | 山姆续费公式收尾：滑到底看到「自己的钱在变多」 |

身份条「回馈金 ¥58.40」为常驻件，不计入新增透出。

## 三、纪律自检（34 号档 + V2 负面清单）

- 色纪律：纸白/深棕墨/卡其/发丝线基底不动；淡金点睛=环+横幅字（深棕面上），每屏 ≤2 成立；无禁用色（柠檬黄/橙/薄荷绿/纯红均未出现）。
- 负面清单七条逐条过：无金刚区 ✓ 无第二促销件 ✓ 无弹窗矩阵 ✓ 卡文案≤2 行 ✓ 无会员玩法楼层 ✓ 无两类混排（案例流纯内容，透出均为信息性数字非 CTA）✓ 楼层数恒定 5 ✓。
- 渲染自验：402×2300 全页截图亲验——瀑布流双列错落成立、chip/点赞/返额各就各位、再约条与账本行单行不挤。（修记录：无头 Chrome 最低窗宽 500 钳制导致首截右缘溢出，solo 页已锁 402px 画布复验通过——此坑已记入复跑说明。）

## 四、候终审的开口项（老板拍）

1. **点赞数上不上卡**：上=社交证明强（小红书范式），不上=更克制（点评式）。我默认上了，嫌吵可摘。
2. **横幅主题**：现稿=「回馈金加速周」；若嫌促销感重，千人千面槽可换「新客首单礼」或季节件（A5 槽位本来就是门店自配）。
3. **案例卡 chip（服务类型标）**：我留了（信任货币逻辑）；若嫌破坏封面纯净度可摘，信息在详情页仍有。

终审过后动作：定稿即铺双态（常态/服务中）+状态变体+施工示意图，交产品侧进施工链；同日可用稿转代码出真骨架交 A 窗试起手（10-08 已入规）。
