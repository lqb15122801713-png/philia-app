## 四、验收集中化（老板 10-01 定的新机制）

- **片间不打断**：A 窗连施五片，每片独立 PR 只开不合+卷宗照写+心跳照写；
- **产品侧**：每片交付做「轻闸」（闸门亲跑+范围核对+卷宗齐件，不打回链不呈老板）；**集中复核**=全批五片交付后一次做（代码逐行审+渲染实证+回退链/槽位点亮抽验）；
- **统一核查+统一走测一次过**：全批合并部署后——B 窗统一核查（闸门真跑复跑+红线实证+入卷核收五卷宗）+QA/运营/UX 统一实机走测一次出动（QA 用例包全批先行/运营刁钻走查/UX 视觉+体验抽审）+老板终审；
- **涉钱片（1/3）双签口径不变**：钱域任一不过=该域打回重修，不混入整批签收。

## 六、反对意见与风险（军规一）

1. **验收集中化=返工后置风险**：五片攒完才发现方向错=大片返工。自保机制=产品侧每片轻闸不断（范围跑偏当场拦），重审集中——若您要更稳，片 1（退款链最涉钱）可单独提前复；
2. **片 3 涉钱+月结撞期**：10-05 首次月结在即，升级补差价施工建议**月结后再动**（防月结快照口径打架），或监理先核月结定时器（PM-01 死线关联件已在监理线）；
3. **P0-9 发票**：电子发票=税务合规域（需开票资质/税控通道），本批只到「申请登记+线下开过渡」，真电票=后期专项——不夸大能力；
4. **触达片等资质**：任务书照写但施工冻结，防「写了当建了」——本批验收时片 5=文档验收（方案层），功能验收=资质到后补；
5. 退款客户端化后，退款量预计上升——门店话术与审批 SLA 归运营配套（运营过稿时钉）。
