### B 股 · 客户流量池化+记账标签（CJ-1009-06 定盘星：瑞幸 ONE SYSTEM 模型）

**定盘星口径**：客户=总公司流量池，**不属于任何店**；钱全进总公司；门店=体验触点+履约端+业绩单独核算。**「客户归属」概念作废，改叫「记账标签」——全链路话术说记账不说归属。**

- 修 1=**店域闸放行**：客户全池可识别可服务（线上注册客户 sold_store=NULL 在收银台 forUser=NOT_FOUND 断链，生产亲验在案）——识别/检索/会员服务全店通；门店数据隔离不下移（订单/账目仍按店隔离照原闸，动的是客户识别层）；
- 修 2=**记账标签**：每笔店域行为（预约/消费/卡办在店）打接待店记账标签（业绩核算到接待店，留痕可溯）——不排他不唯一，客户下次去别家照样服务；
- 修 3=**话术扫面**：码内+端口文案「归属店/归属」字样改「记账标签/记账到 X 店」（grep 零残留实证三通道照更名工艺）；
- e2e 断言随扩：线上客户三店可识别+记账标签留痕+订单级隔离不回退。

**留观察项不并批**：客户档案读取粒度（店员识别后可读到哪层）候 UX/隐私裁——本批只修「识别+服务」通断。
