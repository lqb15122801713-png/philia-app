## 分级缺陷（去重后）

### P0

1. **日结已冻结 vs 同页仍「开班中」且账面继续涨**（敏慧）——一日一结与继续开班冲突，账务口径风险。证据：日结留痕冻结 ¥1371.80 vs 开班中账面现金 ¥2573.60 / 13 单。
2. **员工端端口错指**：任务/文档写 :7201，实为客户端；员工端在 **:7203**（潘婧）。
3. **客户端种子「小美/员工」进宠友壳，无员工入口**（潘婧）。
4. **员工端 tRPC 批量 URL 膨胀 → HTTP 431**（潘婧，`/today`）。
5. **HTTP 无 Geolocation，上班打卡失败**（潘婧，`/attendance`）。
