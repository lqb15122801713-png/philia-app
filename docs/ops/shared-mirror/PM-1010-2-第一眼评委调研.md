# PM-10 ·「第一眼像半成品」解法调研（2026-10-10，老板问：全世界 vibe coding 不可能只有我有这问题）

> 老板痛点：QA/监理测完，他一进去还是发现「不像样」问题——认知层缺陷。查：这层有没有现成武器。

## 有，而且两层都成熟（全世界都在用）

### 第一层：视觉回归测试（变了没有）
- **Playwright 内置截图基线**（`toHaveScreenshot`）：每页存基准截图，版本间像素级对比——哪里变了红哪里；开源免费，我们 e2e 已在用 Playwright，**加截图断言=便宜件**；
- reg-suit/BackstopJS/Loki=同族备选（开源件全免费）；
- 治的病：「这批施工把别屏碰歪了没人知道」——版本间视觉漂移机器盯。

### 第二层：AI 第一眼评委（VLM-as-judge，2026 年标准做法）
- 多模态视觉模型当「**假装第一次看见它的评委**」：每批交付截图→按 Nielsen 十条+「第一眼能不能看懂这页是干嘛的」打分+写评语→低分打回；
- 行业实证：LLM-as-a-judge 进 CI 已是 2026 标准做法（Zalando 生产管线在跑；多模态评测件成熟）；商业件 UI Verify 同款（AI 评委卡 PR）；
- **这就是「老板第一眼」的机器替身**——它不替代你终审，但它让你第一眼看到的东西已经被一个「第一次看见的评委」筛过；
- 实现：自家 Kimi 视觉网关能跑（UX 试屏实证过通道），写个评委 skill+挂闸门族=一天件。

## 落地（并入统一测试方案+验收链）
1. 视觉回归：A 窗闸门族加截图基线（近期件）；
2. **第一眼评委**：写成 skill（评委尺=Nielsen 十条+「这页是干嘛的一眼能懂吗」），挂在产品侧第八步（Argus 人走查截图）之后——截图先过评委，低分件不进你的眼；
3. SUS 真人打分=你终审时的量化尺（已在册）。

## 一句话
「对不对」=闸门+e2e（已有）；「变了没有」=视觉回归（便宜件）；「像不像样」=AI 第一眼评委（新挂号）+Nielsen 尺+你终审。四层全了，半成品感有机器闸。
