## 一、走查四点（任务卡逐项回答）

**① 深色总览卡气质首秀——成立。**
驾驶舱四卡深棕渐变 150deg+纸白 mono 大数 26/700，深色密度位集中首屏一处（四卡一排=一个密度区）——气质对，像「驾驶舱」不像「后台」。**A 窗疑点①裁决：大数纸白（非淡金）判「对」**——本屏淡金负载已高（新增预约 CTA+Rail 当前项+待办淡金点+livetag），四个淡金大数必破预算，纸白是正确保守解；「今日营业额一卡淡金」备选方案登记不执行（签名观感靠卡面本身撑，不靠大数染色）。

**② 信息密度——读起来爽。**
mono 数据位加重+tabular-nums（单号/时间/金额）、金额列右对齐、大数千分分组（财务 ¥5,174 实证）、退款单列/日结双态（bound-cashier-big / bound-dayclose 双态）全部在位；收银台红线口径明面（参考行「不计入已收」次卡/储值分列）✓。

**③ 销项换色件质感——好。**
livetag 同族（深棕底淡金字+呼吸点语义）换上后比原薄荷绿签**更高级**（状态签与深色体系同源了）；赭红警示条（退款 24h 未登记）比纯红柔和但不减警觉——换色净正收益。

**④ 呼吸感——成立。**
页边距收紧 18/16+serif 退为页面题后，台账页（预约/财务/退款/次卡）行密度高而不闷，发丝线行分隔在撑呼吸。MainScaffold 26→18 与旧注释冲突（疑点⑤）——按 34 号档执行是对的，我确认视觉无回退。
