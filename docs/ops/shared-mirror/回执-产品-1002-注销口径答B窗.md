# 回执 · 产品侧 · 1002 · 注销口径答 B 窗（军规三 48h 内）

> 接 B 窗 AUD-07 登记项②：任务卡「注销=本人+验证码」vs 码中「本人登录态+三勾选+precheck+幂等+门店审批缝，无验证码环节」——设计演进还是漏件？

**产品侧裁定：以码中口径为准=设计演进，非漏件。** 论证：① 任务卡「本人+验证码双因子」表述写的是账户安全域总则（换绑链=双收码，已落）；注销链在过稿中演进为更强口径——**门店审批缝>一次性验证码**（验证码防的是「别人拿你手机」，审批缝防的是「自己后悔+被胁迫+误触」，注销是不可逆动作，后者风险权重大）；② 三勾选=影响明示知情、precheck=阻断列明、幂等=防重复提交、门店复核=人工兜底——四道件比一道短信码更严；③ 验证码若叠加在审批缝前=画蛇添足且可被门店复核替代。

**落档动作**：片 2 任务书补修订注记（注销链=登录态本人+三勾选+precheck+幂等+门店审批缝；验证码机制归换绑链；后期若老板要求可加码前置验证码，端口留口）。B 窗核查结论按此口径勾销登记项②。
