# UX-1008 · screenshot-to-code 试屏评估（一页）

> 任务卡：任务-UX-1008-稿转代码试屏（PM，CJ-1008-08）｜执行：UX 设计总监｜2026-10-08
> 对象：abi/screenshot-to-code（本地部署，模型走自家 Kimi 网关 Anthropic 协议，kimi-latest）
> 试件：A-1+ 首页内容丰富化方向稿（402×1900 全页截图）→ React+Tailwind 骨架，4 变体并发，总耗时 6.5 分钟，0 报错。

## 一、骨架还原度几成（结构/样式/素材）

| 维度 | 成数 | 实证 |
|---|---|---|
| 结构 | **8.5 成**（v1/v2） | 11 个区块层全部落位：hero/暖阳会员卡/双预约大卡/回馈金环/再约状态条/毛孩子 chips/案例流双列错落/活动横幅（深棕面）/横滑商品/账本行/底部 Tab。文案 OCR 级还原——「吹完毛的元宝，蓬松成了一朵云」「短腿的倔强：吹风全程骂骂咧咧」「回馈金 ¥58.40 · 周期 9.26-10.25 · 11.5 到账」逐字对 |
| 样式 | **6 成** | 色系方向全对（暖棕+奶油+深棕墨），但全是模型自估 hex：深棕估成 #2D2A26/#2C241B（token=#3B2E24）、淡金估成 #F5E6C8/#F3E5C7（token=#F2DFA6）、纸白估成 #F7F6F2（token=#FAF8F2）。量级/圆角/间距对，token 值必须重擦一遍 |
| 素材 | **1.5 成** | 4 变体中 3 个案例/商品图=色块占位（标 Golden/Corg 字样），v2 自拉外网图（不可控不可用）；icon 用 FontAwesome 凑数。素材本就走素材通道，此维度本来就不指望它 |

变体间质量有差：v1/v2 最佳（v2 布局最贴原稿错落感），v3/v4 把 hero 自由发挥成英文标题（Pet Salon Interior / Salon）——**4 选 1-2 是规定动作，不能拿第一个就用**。

## 二、A 窗从骨架起手 vs 从零摆，省几成

单屏纯摆页约 1 人日量级。骨架直接给全：区块顺序、JSX 结构、Tailwind 类名、全部文案。A 窗剩余规定动作=token 化替换+拆组件进业务域+换素材+接数据。

- **纯 UI 摆页工时：省 3-4 成**；含数据/交互全链路：省 1-2 成。
- 隐性收益：骨架即「可点预览」，视觉走查可提前到代码层做（本次 4 变体我直接渲染成图对照，比看截图审截图直观）。

## 三、值不值得进「UX 出稿→稿转骨架→A 窗施工」流程

**值得，以「可选加速件」进，不当必经闸。** 生成件只当一次性脚手架，可维护红线照查不误——拆件/token/素材「三重写」是规定动作，不许带 CDN 单文件形态进仓。

边界坐实（与任务书互证）：①产出=单文件 HTML+React CDN 形态，非多文件工程，拆件不可避免；②token 色永远要重擦（模型读不出 34 号档）；③素材占位必须换素材通道；④业务逻辑/数据链它不管。

## 四、工程留痕（给 A 窗/PM）

- OpenAI 通道不可用：网关无 Responses API（后端 OpenAI provider 只走 responses.create）；Anthropic 协议通道可用，视觉正常。
- anthropic SDK 必须锁 **0.84**（1.x 删了 temperature 形参，后端 stream 调用直接炸）。
- 接线补丁 3 处：`backend/llm.py`（KIMI_LATEST 枚举+provider 映射）、`backend/agent/providers/factory.py`（ANTHROPIC_BASE_URL 透传）、`backend/routes/model_choice_sets.py`（ANTHROPIC_ONLY_MODELS 改指 kimi-latest）。
- screenshot_preview 工具在 Windows asyncio 下不可用（playwright 子进程 NotImplementedError），不影响生成。
- 部署件留在工作区 `stc/`（含补丁与 .env），随时可复跑；试屏产物 `stc-trial/`（4 变体源码+逐屏截图+对照图）。

## 结论一句话

稿转骨架能扛起「起手件」角色——结构近九成像、样式六成对（token 必擦）、素材别指望；建议进流程当可选加速件，A 窗从最佳变体起手，三重写后照红线施工。

— UX 设计总监 2026-10-08
