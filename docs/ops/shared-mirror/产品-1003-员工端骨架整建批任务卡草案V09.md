## 七、开口项（候老板裁）

1. **范围裁定**：45 件明细=骨架上分批点亮（本卡口径，建议）还是本批全吞（不建议——工期与复核深度双险）？
2. **薪资域边界**：「发放」态本批只留痕不碰真钱（建议口径）——若老板要发放联动线上支付，须等资质三件+线上支付批；
3. **排班-考勤切换风险**：排班表上线后考勤读序切换（排班表优先）——若排班表未排=周模板兜底（零中断）；请老板确认此兜底序；
4. 连锁域预留：排班/薪资实体带 store_id（双归属纪律），但本批只建单店链路（连锁合批再通）。

## 八、反对意见与风险（军规一）

1. 五件同批=面大——骨架纪律（功能全通不雕花）是唯一工期保险；若 A 窗开工后报工期超线，建议按件 1→2→3→4→5 序切片交付（串行不并线照规矩）；
2. 任务总线=只读投影（聚合既有域）——不建新业务表是刻意（防第二口径）；各域在途件口径若漂移，总线跟着漂移=根在各域，不在总线；
3. 断网兜底件有 UX 面（提示文案/申诉入口）——UX 抽审随卷。
