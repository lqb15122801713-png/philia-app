# PM-06 · 人类接管代码调研（2026-10-08，GitHub 插件实证星数）

> 老板问：A 窗施工的内容让人类后续接管的插件/MCP/skill 有没有。（你之前提过一句，本轮用 GitHub 插件实查，星数=插件返回真值）

## 结论：有，而且是大件。推荐三件

| 件 | 星数（10-08 实查） | 干什么 | 对咱们 |
|---|---|---|---|
| **gitdiagram**（ahmedkhaleel2004） | **17,978★** | 任何 GitHub 仓→交互式架构图+一分钟讲解视频 | 人类接管第一眼：一张图看懂 A 窗写的结构 |
| **deepwiki-open**（AsyncFuncAI） | **18,145★** | 代码库自动生成 wiki（自托管，支持 Ollama/OpenRouter） | 人类接管手册：仓里每个域自动出文档，代码变了文档跟着长 |
| **gitingest**（coderamp-labs） | **15,868★** | 仓→一段喂给 AI 的紧凑文本 | 双用：人类导出看全库/新 agent 会话快速读库 |

## 落地建议
- **gitdiagram 即刻可玩**：把仓 URL 里 hub 换 diagram 就出图，零安装——明天就能给仓出第一张架构图；
- **deepwiki-open 入中期包**（与 Langfuse/GlitchTip 同批上 VPS）：每批合部后自动重生成 wiki，人类接管文档永不旧；
- **gitingest 入 A/B 窗工具带**：换会话/新窗读库提速；
- 与 CJ-1008-01 可维护红线配套：**代码写得像人话（A 窗）+文档自动长（deepwiki）+一张图（gitdiagram）=人类接管三件套**。
