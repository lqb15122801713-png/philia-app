### B 股 · 画布化端口（老板 10-07 意向：「形成画布去改和调整，要不谁能看懂那些代码」）

**方案一页（随书呈，老板终审）**：控制台新增第六域「画布端口」——
- v1.1（老板 10-07 两问修正口径）：**右侧真页面实时预览（iframe 嵌真端）+点哪句改哪句**（点画布元素→左侧定位到对应文案键/槽位直接改）+**区块上下拖拽排序**（dnd 换位置）+区块显隐开关+换槽位素材+改文案；
- **拖拽排序可以做**（一天量级，收进 v1）；**不做自由排版**（任意摆放/自由拉伸/新区块类型/断点规则/撤销历史/素材库=Shopify 装修编辑器量级，P2 后期件，不画大饼）——区块是注册表件，布局是 JSON 端口数据；
- 技术路径（端口工艺同族）：block_registry 区块注册表（区块定义+props 端口化）+page_layouts 布局表（页面→区块序列 JSON+版本化+发布两步流）+页面渲染器读布局+预览 iframe 锚点透出（区块/文案键 data-attr 点选反查）——与 copy_overrides/slot_contents 同族，**零新框架零新依赖**；
- 首吃三屏：客户端首页/会员中心/收银台营销位；
- **非工程师验收尺（红线照端口 V2 先例）**：店主在右侧画布点一句文案→左侧定位→改字→预览即变→拖拽换一区块位置→发布→客户端生效，全程无代码概念，走查件一票否决。
