## 〇、开工前 5 分钟（每人必读）

### 1. 证据命名（照抄格式，一字不改）

```
QA40-<用例号>-<机型>-<日期>
```

- 例：`QA40-A1-01-小米14-20260924-录屏.mp4`、`QA40-B2-01-iPad-20260924-01.png`
- 一条用例多张图：末尾加 `-01 -02 -03` 序号；录屏一个文件即可。
- 机型写真实设备名（小米14/iPad9/收银平板…），日期写执行当天 8 位数字。

### 2. 怎么留证据

| 证据类型 | 怎么拍 |
|---|---|
| 截图 | 手机：电源+音量下；平板同；电脑：截图工具。**要拍到完整页面含顶部状态栏** |
| 录屏 | 安卓下拉快捷开关「屏幕录制」；iPhone 控制中心「录屏」。**从点开页面之前就开始录，做完动作再停** |
| 掐表 | 另一台手机开秒表，与录屏同框拍；或录屏后回放读数。**每条计时测 3 次，记下每次读数** |
| 记账数字 | 凡是金额/余额/折扣，**操作前后各截一张**（前值→后值） |

### 3. 三条纪律

1. **遇到任何提示看不懂、卡住、报错**：不要自己琢磨——截图，在用例卡上写「卡住+现象」，继续下一条。QA 会判。
2. **测不了就写「待实测」**（比如没网断不了、设备不支持），写清楚原因，**不许跳过不登记**。
3. 改过错环境（断网、改时间等）**做完立刻恢复**。

### 4. 执行人标记（用例卡开头图标）

- 🧑‍💼【门店】店员/店长照做；
- 👑【店主号】必须用店主（owner）账号登录操作；
- 🔧【产品侧】技术项，门店不用碰，产品侧工程师执行（门店跳过）。

## 二、段 1 · 客户端：注册与会员（A 区 10 条）

**动线**：拿全新手机号 → 客户端注册微光 → 看会员页 → 换付费会员号看识别。

### QA40-A1-01 微光一键注册【门店】⏱️计时
1. 打开录屏 → 另一台手机秒表准备好；
2. 用**全新手机号**进客户端，点「免费开卡 / 开通微光」入口；
3. 从点下注册按钮起掐表，到看到「开通成功/会员页」停表；
4. **重复 3 次**（每次用不同新号或让产品侧重置），记下 3 个读数。
- **预期**：≤30 秒完成；成功后能进会员页，显示「微光」档。
- **证据**：录屏 + 3 次读数写在用例卡空白处 + 成功页截图。

### QA40-A1-02 注册幂等与边界【门店】
1. 用刚才已注册成功的手机号**再注册一次**；
2. 不输手机号/乱输几位数字，点提交；
3. （本步若不方便断网可先跳过，段 8 统一做断网项）。
- **预期**：重复注册不会开出第二个档（提示已是会员或直达会员页）；乱输有明确提示，不白屏不卡死。
- **证据**：两步各 1 张截图。

### QA40-A1-03 安心包全员免费口径【门店】
1. 会员页/权益说明里找「安心包」相关文字；
2. 客户端搜得到的页面都看一眼，重点找有没有「¥15」「非会员 ¥15/次」这类旧字样。
- **预期**：表述=**全员免费**；任何地方不得再出现「非会员 ¥15/次」。
- **证据**：权益表述截图；**若找到 ¥15 旧字样→立刻截图+记页面位置（这是缺陷）**。

### QA40-A2-01 四档展示【门店】
1. 进会员页/开通页，逐档看：微光/萤火/烛光/暖阳；
2. 对照清单核：价格 0 / 199 / 299 / 599；回馈金 无 / 2% / 5% / 10%；服务折扣 无 / 88 折 / 85 折 / 8 折；多宠规则「含 3 只，第 4 只起 +¥59/年/只，10 只封顶」。
- **预期**：全部明面展示，数字与上面**一字不差**。
- **证据**：四档展示整页截图（截不下就分屏截，编号 -01 -02）。

### QA40-A2-02 付费档开通·到店付【门店】
1. 用萤火测试号走一遍开通流程：选萤火 ¥199 → 按页面提示到店付确认；
2. 开通后立刻看会员页档位与权益。
- **预期**：开通后档位立刻变萤火、权益立刻生效；页面有「到店付」字样说明；没有让人误以为已经线上扣款的表述。
- **证据**：流程逐步截图（选档→确认→成功→会员页档位）4 张。

### QA40-A2-03 多宠附加费【门店】
1. 用**暖阳测试号（4 只宠物）**走开通/续费页；
2. 看费用明细。
- **预期**：第 4 只显示 +¥59/年；明细里年费与多宠费**分开列**；如果试着加到第 11 只，有封顶拦截提示。
- **证据**：费用明细截图；封顶提示截图（若能造出来）。

### QA40-A2-04 有效期口径【门店】
1. 进任一付费测试号会员页，看有效期起止日期；
2. 心算核对：到期日 = 开通日 + 365 天。
- **预期**：日期对得上；展示清楚。
- **证据**：有效期展示截图（含开通日+到期日）。

### QA40-A3-01 会员识别·扫码【门店】
1. 收银平板进商家端收银台 → 点「扫会员码」；
2. 用会员号手机出示会员码，扫；
3. 看识别后带出的信息。
- **预期**：识别成功，带出**档位 + 回馈金余额 + 宠物数**。
- **证据**：识别结果页截图。⚠️若摄像头打不开（提示需 HTTPS）：截图记下，用手动输码替代完成本条，并注明「扫码不可用」。

### QA40-A3-02 会员识别·手机号降级【门店】
1. 收银台会员识别处改输**手机号**；
2. 看带出信息是否与 A3-01 一致。
- **预期**：手机号能识别，带出信息一致。
- **证据**：识别结果截图。

### QA40-A3-03 非会员态【门店】
1. 收银台**不识别任何会员**，直接选一个服务进结算页；
2. 看价格与页面。
- **预期**：门市价、无折扣划线、无回馈金抵扣入口；出现「开通萤火立省 ¥X」提示卡（每屏只出现一次）。
- **证据**：结算页截图（含立省提示）。

## 三、段 2 · 收银台四件（B 区 9 条）

**动线**：收银平板 → 售卡 → 服务折扣 → 回馈金抵扣 → 立省钩子。

### QA40-B1-01 售卡四档·到店付【门店】
1. 收银台进会员区 → 选「售卡/开卡」；
2. 分别点看四档：微光（免费开档）/萤火 ¥199/烛光 ¥299/暖阳 ¥599；
3. 用测试号真实售一张萤火：收款（到店付）→ 开通确认；
4. 看售出的单据。
- **预期**：四档价格一字不差；收款+确认两步分明；单据上**不出现「储值/充值」字样**；会员费不进储值余额。
- **证据**：售卡流程截图 4 张 + 售卡单据截图。

### QA40-B1-02 售卡提成定额【🔧产品侧+门店配合】
1. 【门店】完成 B1-01 售卡后，记下售卡单号与售卡员工；
2. 【门店】该员工手机进员工端 → 提成页，找对应行；
3. 【产品侧】核对提成事件=定额 5 元（萤火）/10 元（烛光）/20 元（暖阳）。
- **预期**：提成明细出现该笔，金额=定额，不多不少。
- **证据**：员工端提成明细截图（含单号）+ 售卡单号记录。

### QA40-B2-01 服务折扣自动应用【门店】
1. 收银台识别**萤火号** → 加一项服务（如洗护）进单；
2. 看价格行；再换**烛光号**、**暖阳号**各做一遍；
3. 拿笔算一遍：门市价 × 0.88 / 0.85 / 0.8。
- **预期**：自动打折+门市价划线对照；金额与手算**分毫不差**。
- **证据**：三个档各 1 张结算页截图 + 手算数写在卡上。

### QA40-B2-02 微光/未识别无折扣【门店】
1. 识别**微光号**加服务看价格；
2. 不识别会员加服务看价格。
- **预期**：两种都是门市价、无划线、无折扣。
- **证据**：2 张截图。

### QA40-B3-01 回馈金抵扣·商品行【门店】
1. 识别**有回馈金余额的号** → 加一件商品进单；
2. 支付方式里找「回馈金」段 → 用回馈金抵一部分（余额不足时混搭现金）；
3. 再试一单**全额用回馈金**付（余额够的话）；
4. 看小票/单据明细。
- **预期**：商品单可用回馈金；可全额抵；可混搭；单据里回馈金段单列、**不计入「已收」**。
- **证据**：抵扣操作截图 + 两张单据明细截图（部分抵/全额抵各一）+ 回馈金余额前后截图。

### QA40-B3-02 回馈金抵扣·服务/寄养行硬拒【门店+🔧产品侧】
1. 【门店】识别有余额的号 → 加**服务**进单 → 试着选回馈金支付；
2. 【门店】寄养单同样试一次；
3. 【产品侧】用接口工具直接构造「服务行+回馈金段」请求，看 server 是否硬拒。
- **预期**：前端选不了回馈金（置灰或不出现），并有明文提示；server 直构也拒。
- **证据**：服务行支付页截图（回馈金不可用状态）+ 提示文案截图；产品侧补接口拒绝截图。

### QA40-B3-03 三页同数不破【🔧产品侧+门店配合】
1. 【门店】完成上面含回馈金的交易后，截收银台今日汇总；
2. 【产品侧】截日结页与看板页同口径数字；
3. 三方核对：回馈金在「参考列」单列、营业额合计不受回馈金影响。
- **预期**：三页数字联动一致（照 APP-31 口径）。
- **证据**：三页截图各 1 张。

### QA40-B4-01 立省钩子【门店】
1. **不识别会员**，加商品进结算页 → 看「开通萤火立省 ¥X」；
2. 心算立省金额是否=当单按萤火 2% 算的回馈金；
3. 再识别**付费会员号**进结算页 → 确认不再出现；
4. 同屏来回操作，确认一屏只出现一次、不是弹窗。
- **预期**：金额实时算得对；付费会员看不到；卡片形态不是打断弹窗。
- **证据**：非会员结算页截图（含钩子+金额）+ 付费会员结算页截图（无钩子）。

### QA40-B5-01 新客快速开卡【门店】
1. 收银台找「新客开卡/快速建档」入口；
2. 用一个新手机号现场建档+开微光；
3. 看全程是否顺畅不阻塞后面排队操作。
- **预期**：手机号即建档，微光档当场开通；流程简短。
- **证据**：流程截图（入口→填手机号→成功）3 张。

## 四、段 3 · 回馈金账本（C 区 12 条）

**动线**：有余额的会员号 → 客户端账本页 → 消费返还 → 抵扣 → 退款扣回（接缝实测）。

### QA40-C1-01 返还算法【门店+🔧产品侧】
1. 【门店】识别萤火号 → 买一件 ¥100 商品，现金结账；
2. 【门店】结完看该号客户端回馈金账本；
3. 手算：100 × 2% = ¥2.00。
- **预期**：账本出现该笔返还记录，金额与手算一致；记录注明「本期预计/次月到账」口径。
- **证据**：结账小票截图 + 账本新记录截图（前后余额）。

### QA40-C1-02 无月上限【🔧产品侧】
- 【产品侧】用测试号造多笔/大额商品返还，确认不触发任何月上限拦截。
- **证据**：账本流水截图（多笔累计）。

### QA40-C1-03 用回馈金付的部分不再返【门店】
1. 用有余额的号买商品，**全额用回馈金付**（B3-01 第二单可复用）；
2. 看账本：这单有没有再产生返还。
- **预期**：用回馈金付的部分**不再返**。
- **证据**：该单小票 + 账本流水截图（证明无二次返还）。

### QA40-C2-01 到账周期口径【门店】
1. 账本页找「周期/到账」说明文字；
2. 核对：上月 26 日~本月 25 日为一期、**次月到账**（次月 5 日前）。
- **预期**：页面对外话术统一写「次月到账」。
- **证据**：说明文字截图。⏰真实到账定时器不现场等（归监理+产品侧注入实证，门店不用管）。

### QA40-C2-02 故障顺延明示【门店】
1. 同一页面找顺延说明（顺延≤3 天）。
- **预期**：有明示或口径位置；找不到→截图记「未找到顺延说明」。
- **证据**：截图。

### QA40-C3-01 抵扣红线【门店】
1. 在客户端/收银台所有页面找：有没有「提现」「转让」按钮或入口；
2. 确认回馈金只能用于买东西抵扣。
- **预期**：**全域无提现/转让入口**；有「不提现不转让」规则明示。
- **证据**：规则明示截图；若发现提现/转让入口→立刻截图（P0 级）。

### QA40-C3-02 有效期 365 天【门店】
1. 账本明细点一笔返还记录，看有效期。
- **预期**：标注有效期 365 天（或有明确到期口径）。
- **证据**：明细截图。

### QA40-C4-01 到期冻结/续费解冻【🔧产品侧】
- 【产品侧】造一个到期会员号：看回馈金余额是否「冻结态=在但不可用」；再续费 → 解冻恢复。
- **证据**：冻结态页面截图 + 解冻后页面截图。

### QA40-C4-02 退卡清零【🔧产品侧+门店配合】
- 【产品侧/店主号】对一个测试号执行退会；
- 【门店】配合看该号客户端变化。
- **预期**：回馈金清零 + 档位终止 + 有留痕（前后余额+单号）。
- **证据**：清零前后账本截图 + 留痕记录截图。

### QA40-C5-01 退货按比例扣回（接缝实测，重点！）【门店】
1. 先用有回馈金余额的号**买一单纯商品**（如 ¥100 犬粮），确认返还到账记录（¥2）；
2. 找店长号/店主号对这单**发起退款**（走 R12 退款流程，可退部分）；
3. 退完看回馈金账本：扣回记录 = 该单已发回馈金 ×（退款商品金额÷该单商品总额）；
4. 若余额不足扣，确认扣到 0 为止、不出现负数、有「未扣回」记录。
- **预期**：扣回金额数学吻合；留痕带退款单号；不负账不惊扰。
- **证据**：购买小票 + 返还记录 + 退款单截图 + 扣回流水截图（前后余额），共 4~5 张。**这条是 R12×R11a 接缝，证据务必拍全。**

### QA40-C6-01 五类流水齐全【🔧产品侧】
