# PM-02 · 开源工具链调研：给 Philia 体系加外挂（2026-10-08，老板极致授权）

> 老板令：「很多问题是人类老板发现的……有没有世界上开源的更好用的更适配我们体系的——运营 agent/产品经理 agent/项目经理 agent 的监理，让各窗更智能更专业。我们踩的坑肯定很多人都踩过。」
> 方法：GitHub+全网三圈扫描（规范驱动/多 agent 框架/代码评审 agent/agent 监理可观测/可维护性自动化/浏览器测试 agent），按「我们踩过的坑」映射。

## 一、强烈推荐（三件，直接进体系）

### 1. github/spec-kit（GitHub 官方，125.8k★，MIT）——任务书体系的工业化版本
- **是什么**：规范驱动开发（SDD）工具链：constitution（宪章=不可违原则）→specify（需求规格）→plan（技术方案）→tasks（任务拆解）→implement（AI 实施），每阶段强制人工验证，规范=第一公民、代码=规范的产物。
- **治我们的什么坑**：「老板口径法条化不靠各窗自行理解」（CJ-1008-05 配套三机制）就是 SDD 的手工版——spec-kit 把它工具化；constitution.md 直接装我们的军规+冻结墙；**官方支持 Kimi Code**。
- **落地建议**：产品侧+A 窗下一批试跑（specify=任务书/plan=施工令/tasks=片序），PM 评估后定是否入规。

### 2. knip + dependency-cruiser（npm 两件，零成本）——可维护性红线的机器闸
- **是什么**：knip=扫死代码/未用文件/未用依赖；dependency-cruiser=依赖关系校验+循环依赖巡检+架构越界规则（像 ESLint 一样抛错）。
- **治我们的什么坑**：CJ-1008-01 人类可维护红线（不留死代码/结构按业务域/零新依赖）目前靠 A 窗自觉+B 窗抽读——这两件把它变成闸门脚本，机器查，几十秒。
- **落地建议**：A 窗闸门族直接加两件（npm 零新服务），B 窗核查报告加一行闸门结果。

### 3. qodo-ai/pr-agent（11.4k★，Apache 2.0，2026-04 移交社区）——PR 级 AI 评审补强监理
- **是什么**：挂在 PR 上的 AI 评审员：/review（分级列问题）/describe（自动 PR 描述）/improve（改进建议），GitHub Action 五分钟挂上，中文支持真能用，自托管零锁定。
- **治我们的什么坑**：B 窗核查偏「闸门+实证」，代码逐行评审靠抽核——pr-agent 每个 PR 开出即自动先扫一遍（安全问题发现率提升约 4 倍的实测报告在案）。
- **边界（诚实）**：它不懂业务口径（钱红线/裁定口径仍归 B 窗+QA）；需付 LLM API 费（DeepSeek 通道一次审查约 ¥0.1-0.4）。
- **落地建议**：B 窗主导试点一个批次的 PR，评估信噪比再定。

## 二、中期件（一件，挂账评估）

### 4. Langfuse（MIT，自托管）——agent 监理/可观测=「项目经理的监理」
- **是什么**：记录每个 agent 每一步：调了什么工具、看了什么上下文、烧了多少 token、哪步开始跑偏；会话回放=时间旅行调试。
- **治我们的什么坑**：老板问的「项目经理 agent 的监理」+沟通/token 成本可视化（哪窗最烧钱、哪步在空转）；也能盯「参数冒烟忘复原」类操作留痕。
- **代价**：VPS 自托管一个服务（Docker/helm 半小时件），运维+1。
- **落地建议**：不急着上；等批次节奏稳了，产品侧评估 VPS 承载再上。

## 三、不建议引入（两件，吸收思想即可）

### 5. MetaGPT / ChatDev / CrewAI（多 agent 虚拟公司框架）
- 老板问的「运营 agent/产品经理 agent 建立」=这类。诚实结论：**不值得照搬**——它们是「一个模型分身扮演全公司」的研究框架，擅长三分钟出玩具原型；我们「真人老板终审+各专窗 agent+裁定台账+建查分离」的体系比它们深一个量级。
- **可偷的思想**：SOP 模板化（PRD/测试报告模板）=我们任务书/复核意见书已在走；CrewAI 角色卡自定义轻量=我们角色卡体系同款。无需动作。

### 6. Midscene（字节开源，视觉驱动点界面）
- 重申 10-08 口径：UI 规整 DOM 用不上+视觉 API 按量计费，暂缓；遇视觉死角一句话再装。

## 四、顺手件（可选，不立项）

### 7. chrome-devtools-mcp（Google 官方）
- 操作页面同时读 console/network/performance——画布预览死链这类问题 network 面板一眼看穿；B 窗/A 窗排查顺手件，想用就装，不立规矩。

### 8. browser-use / agent-browser
- 探索式补盲（「点所有可点元素记异常」）——Argus 已覆盖此域，不重复装。

## 五、一句话总结

**马上干**：spec-kit 试一批+knip/dependency-cruiser 进闸门+pr-agent 试点一个 PR——三件都是「把我们已经信的纪律变成机器闸」，零方向风险。**中期**：Langfuse 上 VPS 评估。**不碰**：多 agent 虚拟公司框架（我们体系更深）+Midscene（用不上）。
