## 一、范围（三股合一，一次冻结）

### A 股 · 收银台会员链路修死（缺陷级）

实证在案：server `membership.upgrade` 早已支持微光无缝升档（微光档=新购口径：差价=新档全价、有效期重起算、不退卡不折算），但收银台弹层写死「微光档仍走售卡 mode 不亮升级页签」，而售卡对任何已有会员（含微光）一律拒单——**两条路全堵死，只剩退卡重售**。

1. **升级死路修通**：微光档亮「升级补差」页签（标「新购口径」=首次购卡语义）；售卡页只对纯非会员开放；
2. **读路径缺口补掉**：选中客户即读会员状态（forUser 正式通道已有），售卡页不再误标「新客」、不再等提交撞墙；识别后按状态自动落到对应页签（非会员=售卡／active=升级或续费／frozen=续费解冻）；「内测期读路径缺口，错误原文透出」与「档位读路径缺口」两句登记文案随修撤牌；
3. **错误人话化（裁④=会员域全端点一遍扫净）**：代码标识（membership.renew 这类）永不上屏；人话文案入 copy 端口（非工程师可改照端口 V2 红线）。

### B 股 · 客户端线上升级落缺（membership_upgrade 域，mock 通道）
