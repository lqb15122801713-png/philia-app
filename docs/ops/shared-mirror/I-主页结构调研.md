# I 路调研：APP 首页信息架构——一个首页如何同时承载「内容流 + 会员转化 + 活动 + 电商」

> 调研背景：Philia 客户端首页改版，老板要求首页同时承载四件事——①洗澡美容靓照案例瀑布流（小红书/点评式）②年费会员四档转化（微光免费 / 萤火 199 / 烛光 299 / 暖阳 599）③门店活动介绍（A5 槽位，门店自配）④商品售卖（商城，在码）。
> 对标：小红书 / 大众点评（内容流+团购转化）、星巴克（会员优先首页）、山姆 / Costco（会员制首页）、Petco / Rover（宠物服务）、海底捞（服务品牌）、抖音商城（内容→货架）。
> 产出日期：2026 年（当轮调研）。

---

## 一、各家首页楼层解剖

### 1. 小红书：内容流即首页，商业组件「化装成内容」进流

从上到下：

1. **顶部 Tab 条**：关注 / 发现（默认）/ 本地 + 搜索入口。「发现」双列瀑布流占全站约 80% 流量，是首页主体本身，不是一个楼层。
2. **双列瀑布流（无限）**：图文/视频/直播笔记混排，千人千面推荐（2015 年起）。双列是「最不坏的选择」——兼容一切媒介类型，让用户用「选封面」的方式暴露兴趣，反哺推荐。
3. **商业组件的位置**：信息流广告以「原生笔记」形态插入流内，视觉上与普通笔记几乎一致；购物、直播入口放顶部 Tab 权重位而非占楼层。

**为什么不打架**：小红书的原则是「转化组件必须先伪装成内容」——广告、带货笔记、团购链接都长在笔记卡片里，用户是在「两跳」之后（看封面→读笔记→点链接）才接触转化，首页本身零硬广楼层。代价是转化链路长，但保住了首页的浏览心智。[优设网](https://www.uisdc.com/xiaohongshu-design "citation")，[乱翻书](https://www.xiaoyuzhoufm.com/episode/676e5d051e823e72d332d12e "citation")

### 2. 大众点评：「固定功能区 + 运营楼层 + 内容流」三段式

从上到下（2016 大改版后的骨架延续至今）：

1. **搜索栏 + 品类金刚区**：导航栏分「固定区 + 延展区」——固定区放高频品类满足查找效率，延展区按用户历史行为赛马出新品类，解决「老业务要稳定、新业务要曝光」的冲突。
2. **活动运营楼层**：为你优选（千人千面的活动/优惠，承接价格敏感需求）、每日福利（签到式留存钩子）、特色频道（低频业务引流位）。
3. **内容流（点评头条/笔记流）**：UGC 评价与笔记，承担「决策信息」价值，向团购转化。

**为什么不打架**：点评的核心手法是**给每类目标一个「分工明确的楼层角色」**——金刚区管效率（显性需求）、运营位管贪婪（模糊需求）、内容流管决策（种草）。且明确建议：运营位多放「即时消费、排行榜、品质精选」式内容化运营，少放短期大促硬广——后者「看起来像广告，易引起反感和警戒心，不足以养成点击习惯」。[人人都是产品经理](https://www.woshipm.com/pd/642375.html "citation")，[亿欧](https://www.iyiou.com/news/2016090931485 "citation")

### 3. 星巴克中国 APP：会员优先的「仪表盘式首页」

从上到下（7.16 版本「全新首页」）：

1. **会员身份楼层（首屏核心）**：星星余额、距离下一等级的进度、可用权益、优惠券——首页第一视觉不是商品，是「我的会员状态」。
2. **核心动作区**：啡快/专星送/到店取等点单入口。
3. **内容与活动**：新品、星享俱乐部活动、会员专享。
4. **商城精选**：星礼包、天猫旗舰店导流（星礼卡等）。

**为什么不打架**：星巴克首页是「会员优先」范式——**首页 = 会员仪表盘 + 点单工具**，内容和电商都挂在会员语境之下（新品=积星机会，商城=星礼包）。会员等级（玉星/银星/金星）用「差几颗星升级」的进度条制造常驻转化钩子。效果：会员消费频次是普通用户 3 倍。[人人都是产品经理](https://www.woshipm.com/operate/5257359.html "citation")，[18183 更新日志](https://www.18183.com/down/2919555.html "citation")

### 4. 山姆 / Costco：会员即门槛，首页是「精选货架 + 续费机器」

从上到下（山姆 APP）：

1. **会籍状态 + 配送方式选择**（极速达/全城配/到店）——先确认「你是谁、货怎么来」。
2. **品类导航 + 搜索**。
3. **精选/爆款楼层**：Member's Mark 自有品牌、时令爆品（瑞士卷、烤鸡），SKU 极精选（约 4000 个 vs 传统超市数万）。
4. **猜你喜欢信息流**：按 28 条/月的会员购物记录做需求预判。

**为什么不打架**：山姆首页不为「转化会员」发愁——进门先收 260/680 年费，会员转化发生在**店外与结账口**，首页的任务变成**让会员觉得「值」**：首页每一层都在强化「精选=替你省决策成本=会员费回本」。续费率约 90% 的公式是「（精选产品+品质+独有体验+持续惊喜）×消费频次/价格」。同时山姆擅长「在会员发出需求前先展示新生活方式」（露营装备先行上架），首页是「种草→复购」飞轮的起点。[adquan](https://m.adquan.com/info/detail-352032 "citation")，[什么值得买](https://post.smzdm.com/p/an5gqmmv/ "citation")，[极致零售](http://www.jizhilingshou.com/guandian/2505.html "citation")

### 5. Petco：免费档进门、付费档锁客，APP 首页是「宠物健康仪表盘」

结构（APP + Vital Care 双档体系）：

1. **会员仪表盘楼层**：Vital Care 积分余额、每月奖励到账、宠物健康清单（monthly wellness checklist）、下次美容/疫苗提醒。
2. **服务预约入口**：美容、兽医、训练预约（个性化 dashboard 内直接约）。
3. **商品货架**：营养主粮（会员 10% off）、用品。
4. **双档会员体系**：Vital Care Core 免费（积分、第 8 次美容免费、第 10 袋主粮免费）→ Vital Care Premier $19.99–24.99/月（年承诺，每月返 $15 奖励金、美容 8 折、无限次常规体检）。

**为什么不打架**：Petco 的手法是**「关怀计划」叙事包装一切商业目标**——会员不是折扣卡而是「照护你宠物的更好方式」（care plan framing）；电商复购（主粮）和服务复购（美容、疫苗）被编入「宠物的照护日历」，首页楼层按宠物生命周期而非按公司部门排列。数据：解锁权益的会员到店频次 +50%、花费 +40%，LTV 是普通用户 3.5 倍；2024 财年 Vital Care Core 会员贡献超 90% 交易。[LoyaltyPass](https://www.loyaltypass.co/blog/playbooks/petco-vital-care-loyalty "citation")，[Petco 官网新闻稿](https://corporate.petco.com/2023-01-30-Petco-Unifies-Customer-Memberships-Under-Vital-Care-Program-for-an-Integrated-Omnichannel-Experience "citation")

### 6. Rover：信任信号即楼层，照片流是「履约证明」不是广告

结构：

1. **服务选择器（首屏）**：寄养/上门/遛狗/日托/训练 + 地址 + 日期——首页第一句就是转化表单。
2. **信任楼层**：背景审查、Rover Guarantee（最高 $25,000 兽医赔付）、24/7 支持。
3. **本地保姆卡片流**：评分、回头客数、照片、价格——「人」即货架。
4. **服务中照片更新**：sitter 发 4 张以上照片自动生成 Rover Reel 幻灯片；发照片的 sitter 更容易拿 5 星好评。

**为什么不打架**：Rover 证明了宠物服务业的铁律——**照片是信任货币**。服务过程照片既是履约证明（B 端质量），又是新客决策素材（C 端种草），还是 sitter 营销素材（平台供给端激励）。一套照片三吃，这正是 Philia「七节点照片体系」的直接对标。[Rover 帮助中心](https://support.rover.com/hc/en-us/articles/206353133-How-do-I-send-my-client-photos-during-a-booked-stay "citation")，[Rover 官网](https://www.rover.com/ "citation")

### 7. 海底捞：工具四入口 + 游戏化活动置顶

从上到下：

1. **四大功能入口**：排号 / 预订 / 外卖自提 / 商城——首页是效率工具，3/4 入口服务于「吃」这个核心动作。
2. **顶部轮播活动位**：持续推送互动小游戏（远距辨菜品、移火柴），参与送菜品券，单活动阅读量近 20 万——活动被做成「游戏」而非「广告」。
3. **达人分享/内容区**：用户内容提高留存，间接抬高商城转化。
4. **商城**：新品推荐、热卖榜单、周边、积分兑换（堂食 50 元代金券换购 31 万份）。

**为什么不打架**：海底捞首页的优先级是**核心服务动作 > 游戏化活动 > 内容 > 商城**。电商从不抢服务的位置；活动用游戏外壳降低广告感。会员系统（5 级、捞币）打通堂食+外卖积分，权益渗透在每个动作里而不是单独楼层叫卖。[新浪财经/界面](https://finance.sina.cn/2021-08-27/detail-ikqciyzm3930526.d.html "citation")，[海底捞官网](https://www.haidilao.com/member/membership/interests "citation")

### 8. 抖音商城：内容场→货架场的「双场联动」范式

商城首页结构（对齐淘系验证过的架构）：

1. **顶部菜单 + 搜索框**。
2. **中部四宫格板块**：品牌馆、直播、补贴等营销楼层。
3. **下方猜你喜欢信息流**：商品卡、短视频、直播间混排，按「内容观看 + 商品消费」双历史推荐。

**为什么不打架**：抖音的关键机制是**信号联通**——内容场（短视频/直播）里表现好的商品信号（GLM）传给货架场，进入商城「猜你喜欢」推荐池，完成「种草在内容场、收割在货架场」。首页信息流里直播间占比高，是因为那是转化效率最高的内容形态。2022 年起商城入口常态化在顶部「右侧第二位」黄金资源位——顶部和底部是「所有手机应用的黄金资源位和新功能试验田」。[LatePost](https://www.latepost.com/news/dj_detail?id=2417 "citation")，[钛媒体/电商在线](https://www.163.com/dy/article/HFUQ5D0I05118513.html "citation")

## 二、四类目标共存的手法（不打架的六条规律）

从上面八家抽象出来的共性规律：

**规律 1：一个首页只能有一个「主体心智」，其余目标挂靠在它下面。**
小红书的主体是内容流，星巴克/Petco 的主体是会员仪表盘，海底捞的主体是服务工具，山姆/抖音的主体是货架。四目标平起平坐的首页不存在。对 Philia 而言，主体心智应该是**案例内容流**（老板痛点是「首页内容不够丰富」，且七节点照片体系是独有素材源），会员/活动/商城都以「不破坏浏览流」为前提嵌入。

**规律 2：转化组件进入内容流的两种合法姿势——「伪装成内容」（小红书）或「夹在语境里」（抖音 GLM）。**
前者：会员卡、活动卡、商品卡做成与案例卡片同尺寸同视觉的流内卡片；后者：案例详情页/流内挂「同款」「这位宝贝用的是 XX 浴液」——内容信号直接导货架。禁止的姿势是点评警告过的「短期大促硬广楼层」，会引发警戒心且不养成点击习惯。

**规律 3：节奏密度——转化组件的流内占比大约 1:6 ~ 1:8，且越靠首屏越软。**
参照系：小红书信息流广告密度长期控制在约 10% 上下；点评把硬转化放固定楼层、流内只做软运营；抖音商城猜你喜欢里直播间占比高但均以内容形态出现。落地口径：**每 6–8 张案例卡插 1 张转化卡；首屏（前 1–2 屏）只放轻转化（会员身份条、活动横滑），重转化（商品卡、办卡利益点卡）从第 2–3 屏开始。**

**规律 4：会员转化的最高效位置是「状态栏化」——做成常驻身份层而非偶发 Banner。**
星巴克把「差几颗星升级」放首页第一楼层；Petco 把「本月 $15 奖励已到账」做成仪表盘；山姆首页先显示会籍状态。年费四档的 Philia 应学这一点：免费（微光）用户看到的是「升级萤火可省 ¥X」的常驻轻条；已付费用户看到的是「权益使用进度」——**对未付费者是转化钩子，对已付费者是续费铺垫（山姆续费公式：让会员觉得「值」）**。

**规律 5：活动位的最佳形态是「游戏化/日历化」，而不是促销海报。**
海底捞把活动做成小游戏（送菜品券）、Petco 把活动做成照护日历提醒（该驱虫了/该美容了）。Philia 的门店活动（A5 槽位）应包装成「本周门店日历/可报名的场次」，而非「打折海报」。

**规律 6：照片是宠物行业的信任货币，一套素材要吃三次。**
Rover 证明：服务过程照片 = 履约证明 + 种草素材 + 供给端激励。Philia 七节点照片体系产出物应同时供：①首页案例瀑布流（种草）②案例详情里的「同款商品/服务套餐」转化锚点（电商）③会员权益的具象化证明（「暖阳会员全年免费洗澡」用真实案例展示）。

## 三、落到 Philia 的首页楼层建议方案

**总原则：主体心智 = 门店真实案例瀑布流；会员 = 常驻身份层 + 流内节点转化；活动 = 首屏横滑日历槽；商城 = 流内「同款」锚点 + 金刚区入口，不在首页做独立货架楼层。**

从上到下逐层：

| 层 | 组件 | 内容 | 转化目标 | 为什么在这一层 |
|---|---|---|---|---|
| **L0 顶栏** | 门店定位 + 搜索 + 消息 | 当前门店名（可切换）、案例/商品搜索 | 无（导航层） | 所有内容都与「这家店」绑定，先确立门店语境（Petco/点评的 LBS 逻辑） |
| **L1 会员身份条**（常驻、极轻、一屏高内） | 微光用户：「升级萤火 ¥199/年，本单立省 ¥X」+ 右箭头；付费用户：等级徽章 + 权益进度（如「全年免费洗澡已用 3/12」） | 会员状态仪表盘 | **会员转化/续费第一触点** | 星巴克/Petco 验证：身份层置顶的会员转化效率高于任何 Banner；对付费者的权益进度是续费铺垫（山姆「值」公式） |
| **L2 快捷金刚区**（4 枚） | 预约洗澡美容 / 商城 / 门店活动 / 我的宠物档案 | 工具入口 | 预约直达 + 商城入口 | 海底捞验证：核心服务动作必须给一个不用刷流也能直达的出口；商城在此获得固定入口，补偿首页不做货架楼层 |
| **L3 活动横滑槽**（A5 槽位） | 门店自配活动卡片横滑，「本周日历」式包装：周六洗护体验课、会员日、节日派对，可一键报名 | 门店活动 | 活动报名/到店 | 首屏末/二屏首的黄金衔接位（点评运营位逻辑）；「日历/场次」形态规避硬广感（海底捞游戏化思路的服务业版本）；门店自配正好落在固定槽位，不污染案例流 |
| **L4 案例瀑布流·首段**（第 1–2 屏，纯内容） | 双列瀑布流，门店真实服务案例（七节点照片体系素材）：美容前后对比、洗护过程、宠物状态 | 种草、停留时长、「内容丰富」的老板诉求 | 无硬转化（可有点赞/收藏） | 小红书验证：先给纯内容建立浏览心智；双列兼容图文/短视频，且让用户用选封面暴露兴趣 |
| **L5 流内转化节奏**（第 3 屏起，每 6–8 张案例插 1 张转化卡，循环） | 三种转化卡轮替，全部与案例卡同视觉：①**会员利益卡**——「这只布偶是暖阳会员，全年洗澡 0 元」附办理入口；②**同款商品卡**——「本案例同款沐浴露」挂商城 SKU；③**活动预告卡**——下场活动报名 | 会员办理 + 商品下单 + 活动报名，按 4:3:3 左右轮替 | 小红书「伪装成内容」+ 抖音「内容信号导货架」双手法；案例语境让利益点具象（照片证明权益真实发生过） |
| **L6 无限流 + 底部 Tab** | 案例流持续；底 Tab：首页 / 商城 / 发布或预约 / 消息 / 我的 | — | 商城在底 Tab 有第二固定入口 | 抖音验证：顶部与底 Tab 是黄金资源位；商城「在码」期间先用金刚区+底 Tab 双入口过渡，首页内不急着建货架楼层 |

**密度口径（给设计/运营的红线）**：
- 首屏（L0–L3）只允许一个硬转化件（L1 身份条是常驻件不算）；
- 流内转化卡占比 ≤ 1/6，且连续两张转化卡之间至少隔 6 张案例卡；
- 商品卡必须挂「案例同款」语境，禁止裸商品卡进流；
- 活动全部收进 L3 槽位和流内预告卡，禁止额外弹窗/悬浮球（会员到期提醒除外）。

## 四、反例警示（首页做砸的通病）

1. **百货商场式堆楼层**：搜索、banner、金刚区、秒杀、领券、直播、榜单、内容流一字排开十几层，每层楼都是某个业务线要的资源位，用户两屏看不到内容主体。点评/淘宝系都有过这个阶段，解法都是「赛马机制」——楼层位置按 CTR 竞争，优化差的业务自动下沉，而不是谁嗓门大谁占坑。
2. **硬广大促进首屏**：点评明确警告「短期大促类内容看起来像广告，易引起用户反感和警戒心，且不具有持续性，不足以养成点击习惯」。Philia 若把「萤火 199 限时立减」海报放首屏 Banner，既吓跑内容浏览者，点击也养不成习惯——会员转化的正确位置是身份条 + 案例语境。
3. **首页做商城货架层，与底 Tab 商城左右互搏**：抖音/淘宝的做法是货架场有独立首页（商城 Tab），主端首页只做「信号导流」。Philia 商城在码阶段若提前在首页铺商品货架层，会同时稀释案例流的丰富感和商城 Tab 的存在意义。
4. **会员体系做成「折扣卡」叙事**：Petco 的教训是会员必须包装成「照护计划」（care plan）而非「打折卡」——折扣卡谁都能抄，且只吸引价格敏感一次性用户；年费四档要绑定宠物的照护节奏（洗澡周期、美容周期、驱虫疫苗日历），才有续费。另忌「档位权益算不过账」（用户一算觉得亏，口碑死亡）和「多币种多规则复杂化」（变成客服问题）。
5. **交易之间沉默**：多数会员计划只在收银时出现。Petco/Stabucks 首页仪表盘的价值在于「用户不在店里时也提醒他权益的存在」——Philia 首页的权益进度条和「本月会员专属案例/活动」承担这个反沉默职能。
6. **内容流冷启动用运营凑数图**：案例流的可信度来自「本店真实服务记录」（七节点照片），若用网图/摆拍填充，等于自毁 Rover 式信任货币，团购转化和会员转化会一起塌。
7. **弹窗/悬浮球叠罗汉**：活动弹窗 + 会员弹窗 + 优惠券弹窗同开，是工具型首页最常见的自杀方式。原则：首页一切诉求要么进固定楼层，要么进流内卡片，要么进 push，不许抢首屏拦截层。
