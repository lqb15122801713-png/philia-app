- **页面落点**：商家端日结界面（收银台日结弹层/日结提交页），「今日已收」金额区下方加一行：

- **页面落点**：商家端 dashboard 营业额卡片，金额下加一行小字口径注：
  - `含售卡实收 ¥Y；分摊确认口径 ¥X（本月）`
- 与收银台头部、日结账面三处同数字源，防三页打架（32 号档 §七已实证三页同数 ¥5,805.64，加行后保持）。
