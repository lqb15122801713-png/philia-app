# Philia 项目档案（docs/ops）

> 全项目唯一跨会话事实源（CJ-0921-06：各会话本地沙箱互不可见，档案真身只在本目录）。
> 任何角色窗口开工第一步：**用 github 工具读取本目录全部文件**，从《03_角色卡汇编》找到自己的角色进入。

## 三层架构（军规五）

| 层 | 文件 | 更新频率 | 写入权 |
|---|---|---|---|
| 事实层（宪法） | 01 章程 / 02 台账 / 03 角色卡 / 07 总纲 | 低（裁定触发） | 仅项目经理 |
| 状态层（实时） | 09 实时工作看板 | 实时 | 各窗口写自己行 |
| 工作层（高频） | 04 对账表 / 06 盘点表 / 08 原始记录 / 10 调研报告 / 11 审美基准 | 高 | 按各文件规则 |

## 纪律

1. 新裁定 → 项目经理 24h 内记入《02_老板裁定台账》；
2. 状态变化 → 各窗口更新《09_实时工作看板》自己行（开工/收工/阻塞必更）；
3. 交付三件套：三端走测图+对账表+发放说明，缺一件打回；
4. 七条军规见《07_协同工作总纲》——不顺着老板说 / 不自检不提交 / 质疑与牵制 / 工具授权隔离 / 三层共享 / 效率第一 / 目标共识。
