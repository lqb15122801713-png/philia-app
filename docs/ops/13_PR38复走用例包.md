3. **计时纪律**：计时复核两遍（军规二 QA harness）。每条计时用例测 3 次，**最大值与中位数双记**，最大值超线即 ❌。
4. **弹窗暂行口径（待裁定，先按此执行）**：「零弹窗」= 浏览器原生 alert / confirm / prompt 及营销、授权类打断弹窗为 0；设计内页面级确认流（配置端口重确认 D 套等）不计入。裁定落地后按裁定口径改判 B4。
5. **双层标记分离**：本包只判「功能实现已确认」；「数据结构已确认」归监理核查域，本包不标。
6. **QA 边界**：只上报不指挥施工；改进方向为建议性质，方案归产品经理。

## 七、掐表与击数口径（计时方法学）

1. **击数**：手指有效点击次数，页面就绪后起算；聚焦输入计 1 击，逐字输入不计。
2. **计时**：录屏逐帧读数（30fps 下帧粒度 33ms）或系统秒表 + 录屏双轨互校；LCP 用 DevTools Performance（4G 节流预设）。每用例 3 次，最大值 + 中位数双记，最大值超线即 ❌。
3. **环境登记**：机型 / OS / 浏览器或微信 / 网络态 / 电量；低端机动效降级单独标注。
4. **读数不得编造**：测不到就标「待实测」，不估不凑。
