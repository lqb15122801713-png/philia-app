## 〇、执行口径（动手前先读）

1. **分工（CJ-0921-07）**：真机操作 = 运营 / 门店；QA 出用例、收证据、下判定。无证据不判定。
2. **证据链**：每条用例须留——机型 / 系统 / 浏览器 / 网络态、录屏或连续截图、计时读数（掐表法见 §八）。证据命名：`QA38-<用例号>-<机型>-<日期>`（PR #38 域）/ `QA39-<用例号>-<机型>-<日期>`（R12 域），归 evidence 体系永久保留。
3. **计时纪律**：计时复核两遍。每条计时用例测 3 次，最大值与中位数双记，最大值超线即 ❌。计时统一口径 = 4G 节流 LCP（CJ-0921-12⑤ 采纳）。
4. **弹窗口径（已定）**：零弹窗 = 原生 alert/confirm/prompt 及营销、授权类打断弹窗为 0；设计内确认流（重确认 D 套、离线状态条、toast、退款预览页等）不计。
5. **双层标记分离**：本包只判「功能实现已确认」；「数据结构已确认」归监理（R12 域监理已标 APP-39/40，辅证 APP-27/30/35/44）。
6. **QA 边界**：只上报不指挥施工；改进方向为建议性质，方案归产品经理。
7. **判定词（V1.3 起）**：✅通过=证据充分（注明来源：走查/监理/生产 smoke）；⚠️部分通过=主链路已证、子项待证（列明）；❌不通过=证据证伪或冻结规范违反（缺陷在案）；待实测=无有效证据。
8. **首轮证据形态声明（2026-09-22 轮）**：功能判定证据 = 运营走查（Chromium 桌面 393×852 视口 + Beta 三端实机域名 + 生产库真实数据）+ 监理独立代码核查 + 生产 smoke 65 项；**计时/击数/定位/摄像头/离线流 = 真机口径项，本轮一律待实测**，HTTPS 化 + 真机复走日补验（缺口已办结：T11 隧道三通 + 双身份号在册）。

## 八、掐表与击数口径（计时方法学）

1. **击数**：手指有效点击次数，页面就绪后起算；聚焦输入计 1 击，逐字输入不计。离线打卡击数与在线同口径（≤2 击，17 号 §五.2）。
2. **计时**：录屏逐帧读数（30fps 帧粒度 33ms）或系统秒表+录屏双轨互校；LCP 用 DevTools Performance（4G 节流预设）。每用例 3 次，最大值+中位数双记，最大值超线即 ❌。
3. **补传节奏观测**：退避 2s/8s/30s 不肉眼估——录屏时间轴+服务端 uploaded_at 时刻差互核。
4. **环境登记**：机型/OS/浏览器或微信/网络态/电量；低端机动效降级单独标注；改机时间类用例测后必须恢复设备时间。
5. **R12 无专项计时条款**；体验关仅加载 <2s（F5-03）+ 零弹窗（F5-02）。
6. **读数不得编造**：测不到就标「待实测」，不估不凑。
